# 第四章 蛋白质的功能

蛋白质是生物体各项功能的主要执行者。然而，任何一种蛋白质的功能都与其独特的结构密不可分，特别是三维结构。揭示蛋白质的功能与其结构之间的关系是当今蛋白质研究领域最重要的内容之一，而根据一级结构的信息预测一种多肽或蛋白质的三维结构，并进而对其功能进行预测也一直是生物化学家的终极目标。

本章首先会简单地总结一下蛋白质在机体内行使的主要功能,然后重点介绍蛋白质的功能与其结构之间的关系,最后再分析几种常见的蛋白质的功能及其与结构之间的关系。

## 第一节 蛋白质的主要功能

在某种意义上,每一种蛋白质都可视为一种独特的生物功能试剂,因为生物体内的每一项功能几乎都涉及一种或几种甚至多种特定的蛋白质。

迄今为止，已被发现的蛋白质的生化功能主要包括以下几项。

（1）催化。充当绝大多数酶，催化机体内的各种生化反应(参见第九章“酶学概论”)。

（2）调节。既可以调节其他蛋白质(包括酶)的活性,又可以调节基因的表达。例如,周期蛋白调节 CDK 的活性,阻遏蛋白(repressor)和激活蛋白(activator)分别抑制和激活特定基因的表达。

（3）运输。例如，血红蛋白运输氧气，转铁蛋白(transferrin)运输 $Fe^{3+}$ ，白蛋白运输脂肪酸，载脂蛋白运输脂质，质膜上的转运蛋白运输进出细胞的多种物质。

（4）贮存。例如，铁蛋白（ferritin）为细胞贮存铁，肌红蛋白为肌肉细胞贮存氧气，酪蛋白(casein)和卵清蛋白为动物的生长发育贮存氨基酸。

（5）运动。例如，鞭毛蛋白（flagellin）参与细菌和古菌基于鞭毛的运动，肌动蛋白（actin）和肌球蛋白（myosin）的相互滑动导致肌肉细胞收缩或松弛。

（6）结构支持和保护。例如，胶原蛋白在动物的结缔组织中主要起结构支持的作用。再如，许多古菌的细胞壁的主要成分是蛋白质。

(7) 信号转导。例如,胰岛素及其受体的相互作用导致血糖浓度的下降(参见第十八章“激素”)。

(8) 免疫。例如,抗体和 T 细胞受体分别参与体液免疫和细胞免疫。

（9）其他功能。包括一些仅存在于某种或者某些特别的生物体内奇异的功能。例如，来自南极鱼体内的抗冻蛋白可帮助南极鱼抵御严寒，来自某些节肢动物的弹性蛋白(resilin)和由某些海洋动物(如贻贝)分泌的胶蛋白分别具有超强的弹性和黏性。

然而,并不是一种蛋白质只能行使一种功能。自上世纪80年代以来,科学家已发现了一些蛋白质虽然只有一种结构,但是却能行使几种甚至多种不同的功能。这些兼有其他功能的蛋白质被称为兼职蛋白(moonlighting protein)。例如,许多动物体内的己糖磷酸异构酶除了在细胞内参与糖酵解,还能由T淋巴细胞分泌到胞外充当一种神经白介素(neuroleukin),促进胚胎内某些神经元的存活,以及促进B淋巴细胞的成熟;再如,人体细胞内参与糖酵解的甘油醛-3-磷酸脱氢酶可以在细胞核里做兼职,作为尿嘧啶-DNA糖苷酶,参与DNA的碱基切除修复(参见第三十六章“DNA损伤、修复和突变”)。这些兼职蛋白一开始可能只有一项功能,但进化赋予了它们新的功能。

一种兼职蛋白在体内究竟行使何种功能,取决于它的亚细胞定位、表达于何种细胞、以单体还是多聚体形式存在、与其他蛋白质或大分子的相互作用、与其结合的配体（ligand）分子在细胞内的浓度等因素。

以顺乌头酸酶为例,它在线粒体基质中就是催化三羧酸循环的第二步反应,但在细胞质基质中,则作为一种铁感应蛋白,有助于维持胞内铁离子水平的稳定。

想认识更多的兼职蛋白,可访问专门的数据库——MoonProt。目前,该数据库已罗列了512种兼职蛋白,其网址是http://moonlightingproteins.org。

蛋白质在行使功能的时候,通常都会涉及与配体的结合。因此,可根据配体的性质,来对蛋白质的功能进行分类。与蛋白质结合的配体可以简单地分为两类:一类是配体在结合以后,化学结构会发生变化,变成了另外一种配体。例如,酶在催化反应的时候,作为配体的底物在与酶结合以后,受到酶的催化,变成了产物这种配体;另一类是配体在结合前后并无化学的变化。例如,氧气和血红蛋白的结合以及激素与受体的结合。

## 第二节 蛋白质结构与功能关系的一般规则

蛋白质的结构与功能之间的关系,一直是生化学家最关注的问题之一。在经过对多种蛋白质的结构与功能关系研究的基础上,科学家已总结出了其中的一些基本规则,共包括以下七个方面。

1. 蛋白质的一级结构决定其三维结构，而三维结构直接决定蛋白质的功能。

2. 大多数蛋白质在合成后, 就会折叠成特定的三维结构, 并开始行使其功能。一旦三维结构被破坏, 功能随之丧失。少数蛋白质在体内可暂时处于天然无折叠状态, 但在需要时可迅速折叠并行使它们的功能, 还有少数蛋白质就是以无折叠状态行使功能 (参见本章有关天然无折叠蛋白质的内容)。

3. 蛋白质在行使功能的时候一般会经历三维结构或构象的变化。这种构象的变化可能是剧烈的，也可能是细微的。

4. 结构相似的蛋白质一般具有相似的功能。反过来,功能相似的蛋白质通常具有相似的结构,特别是三维结构。

这项规则对于预测一个序列已知的蛋白质的功能有时很有用。例如，假定有一天我们在某一种生物体内发现一种新的蛋白质，并获得了它的一级结构，这时就可以在蛋白质序列数据库（Genbank、PIR或Swiss-PROT）里进行查询和比对，看数据库里面有无功能已知的蛋白质与要研究的这种蛋白质序列相似。如果有，那么我们正在研究的这种蛋白质的功能很有可能与数据库中这种已知功能的蛋白质相似，甚至相同。序列相似度越高，可能性就越大！若是要利用Genbank中的序列，可利用其网页上的在线程序BLAST（basic local alignment search tool）的Protein BLAST子程序来进行。Protein BLAST可将数据库中所有与我们研究的蛋白质序列具有相似性的蛋白质搜索出来，这时我们可以把序列相似度 $>30\%$ 的所有蛋白质序列下载到所用的计算机的一个指定目录下。然后，将这些蛋白质以及我们研究的蛋白质的序列交给专门的多重序列比对软件（如ClustalW或POA）进行比对分析。最后，还需要将比对的结果交给专门的进化树绘制软件（如MEGA或PHYLIP）来绘制进化树。我们研究的蛋白质与进化树中靠得最近的蛋白质在功能上应该最有可能相似或相同。当然，通过这种方法预测出来的蛋白质功能最终还需要设计实验来进行验证。

5. 在不同物种体内功能相同的蛋白质具有相同或基本相同的三维结构,但一级结构是否有差异以及差异的程度往往取决于物种之间在进化上的亲缘关系。

以组成有氧生物呼吸链的细胞色素 c 为例, 这种蛋白质存在于所有的有氧生物体内, 作为一种膜外在蛋白, 结合在原核生物的质膜和真核生物的线粒体内膜的表面, 其功能是作为一种流动的电子传递体, 往返于呼吸链的复合体Ⅲ和Ⅳ, 进行电子的传递 (参见第二十一章 “生物氧化”), 但真正传递电子的是细胞色素 c 的血红素辅基上的铁离子。在对多种不同来源的细胞色素 c 的晶体结构进行研究后发现，它们在三维结构上都惊人地相似。而在对 40 种不同的真核生物的细胞色素 c 的一级结构进行比较分析后还发现，在构成细胞色素 c 的 110 个左右的氨基酸残基中，28 个始终不变，这意味着这 28 个残基是细胞色素 c 形成正确的三维结构并行使正常功能所必需的。进一步的研究结果还表明，在这 28 个高度保守的氨基酸中，有 3 个 Gly、2 个 Cys、1 个 His 和 1 个 Lys。其中的 3 个 Gly 在所有的细胞色素 c 分子中都是绝对保守的，而 2 个 Cys 和 1 个 His 关系到血红素辅基与细胞色素 c 的共价及配位结合，因此也是不可变更的。至于这个 Lys 残基，涉及细胞色素 c 与膜的结合，因而也是高度保守的。从二级结构的层次来看，保守的氨基酸多分布在无规卷曲中，还有若干 β 凸起高度保守。这与无则卷曲通常与蛋白质的功能关系密切，以及 β 凸起通过细调肽链的走向而影响细胞色素 c 最终三维结构的形成是一致的。

Quiz3 你认为人与黑猩猩编码细胞色素 c 的基因的一级结构一定相同吗？

很多人喜欢根据蛋白质一级结构的相似性来研究生物进化。一般说来，两种生物的亲缘关系越近，它们的基因和蛋白质的一级结构就越相似。

在蛋白质的进化过程中,有两种不同的机制可产生两类结构相似、功能相似的蛋白质:一类是类似物(analog),即类似蛋白,另一类是同源物(homolog),即同源蛋白。

（1）类似物。专指具有相同的功能，但起源于不同的祖先基因的蛋白质，它们是基因趋同进化（convergent evolution）的产物。例如，鼠疫杆菌（Yersinia pestis）和牛都合成一种酪氨酸磷酸酶（tyrosine phosphatase）。这两种生物产生的酪氨酸磷酸酶在活性中心的三维结构十分相似，活性也相似，但一级结构差别很大，显然它们是从完全不一样的祖先基因进化而来的。再如，枯草杆菌合成的枯草杆菌蛋白酶与哺乳动物消化道分泌的胰蛋白酶、胰凝乳蛋白酶和弹性蛋白酶都属于丝氨酸蛋白酶，虽然它们的活性中心都含有由Ser、His和Asp组成的催化三元体（参见第十一章“酶的催化机制”）的结构，但是在一级结构和三维结构上差别很大，因此它们也来自不同的祖先基因。

4-2 同源物、直向同源物和种内同源物之间的关系


（2）同源物。专指存在于不同生物或者同种生物，来源于某一共同祖先基因的蛋白质（图4-2），可进一步分为种间同源物（ortholog）和种内同源物（paralog）。种间同源物也称为直向同源物或直系同源物，是指来自于不同物种的由垂直家系（物种形成）进化而来的蛋白质，它们通常保留与原始蛋白相同的功能，但也不尽然。例如，小鼠、蛙和鸡各自的α珠蛋白或β珠蛋白。种内同源物也称为旁系同源物，是指同一物种内由于基因复制、分离产生的同源物。例如，蛙、鸡和小鼠各自的α珠蛋

白和 $\beta$ 珠蛋白。通过进化,种内同源物可能会获得新的功能,但新功能多少会与原来的功能有一定的关系。

同源蛋白具有相似的三维结构,这是同源建模获得蛋白质三维结构的理论基础。现有多种专业软件可对以上情形进行分析,如 ClustalX,还有许多网站提供在线分析服务,如欧洲生物信息学中心 (European Bioinformatics Institute, EBI) 提供的 http://www.ebi.ac.uk/clustalw/,这为在分子水平上研究进化提供了便利。

## 第三节 几类重要的蛋白质的结构与功能

## 一、纤维状蛋白质的结构与功能

Quiz4 你认为纤维状蛋白通常缺乏何种二级结构？

纤维状蛋白质结构伸展,呈纤维状,长/宽>10,一般不溶于水,机械强度高,化学反应性较差。它们的主要功能是在结构上为机体提供支持和保护,例如α角蛋白、β角蛋白和胶原蛋白。纤维状蛋白质之所以能折叠成有规律的纤维状结构,是因为它们的一级结构具有高度的规律性——氨基酸残基的种类有限,但序列通常以重复单元的形式出现。

## (一) $\alpha$ 角蛋白

α角蛋白因二级结构主要是α螺旋而得名。它广泛存在于动物的毛发、角、鸟喙和爪子等结构之中，可分为I型和Ⅱ型等不同的亚型。其一级结构由311~314个氨基酸残基组成。每一个α角蛋白分子在肽链的中央形成典型的α螺旋，而两端为非螺旋区。

螺旋区由七肽重复序列模体—— $(a-b-c-d-e-f-g)_n$ 组成， $a$ 位和 $d$ 位刚好为疏水氨基酸。这样的分布让2个 $\alpha$ 角蛋白分子可通过 $a$ 位和 $d$ 位的疏水R基团结合，并相互缠绕形成一种双股的左手超螺旋，即卷曲螺旋。卷曲螺旋大大地提高了 $\alpha$ 螺旋的稳定性。此外，在链间还有二硫键，这种共价交联可进一步提高 $\alpha$ 角蛋白的强度。指甲的强度比毛发高是因为含有更多的Cys残基，能形成更多的二硫键。 $\alpha$ 角蛋白分子还可以在双股卷曲螺旋的基础上，先形成原纤维，然后再由原纤维组装成纤维（图4-4）。

在美发过程中,无论是卷发还是直发,原理都一样:先用还原性的巯基类化合物(如巯基乙酸铵或半胱氨酸)破坏二硫键(约45%的二硫键断裂),使之被还原成游离的巯基,易于变形;再用发夹和发卷将头发塑成一定的形状(卷发让头发成为波状,直发则将头发拉直);最后用氧化剂(如溴酸钠或过氧化氢)重建二硫键,使发型固定下来。

## (二) $\beta$ 角蛋白

$\beta$ 角蛋白则因二级结构主要是 $\beta$ 折叠而得名，大量存在于蚕丝和蜘蛛丝之中。其一级结构富含Ala和Gly，具有二肽重复序列模体——（Gly-Ala/Ser）；它的二级结构主要是反平行 $\beta$ 折叠，还有一些环绕在 $\beta$ 折叠周围的 $\alpha$ 螺旋和无规卷曲(图4-5)。有序的反平行 $\beta$ 折叠构成丝的微晶（crystallite）区，由于Gly和Ala/Ser分别分布于折叠片层的两侧，相邻的 $\beta$ 股能更加紧密地堆积形成网状结构(图4-6)，从而赋予丝较高的抗张性。而无序的 $\alpha$ 螺旋和无规卷曲构成无定形区，又使丝具有一定的弹性。

作为天然的生物材料,蚕丝和蜘蛛丝都很有用。但同样是丝,蜘蛛丝的强度和弹性要明显高于蚕丝。有实验显示,一束由蜘蛛丝组成的绳子比同样粗细的不锈钢钢筋能多承受5倍的重量,这相当于是一根铅笔粗细的蛛丝能阻止一架波音747飞机的飞行!

胶原蛋白的基本组成单位是由3条 $\alpha$ 链组成的原胶原（tropocollagen）。其中有2条相同的 $\alpha_{1}$ 链，第3条链为 $\alpha_{2} \circ \alpha_{2}$ 在组成上与 $\alpha_{1}$ 有所差别。不同类型的原胶原由于 $\alpha$ 链的氨基酸组成及含糖量不同，因而性能也不同。在人体内已发现的近29种不同类型的胶原蛋白中，I型最多，占 $90\%$ 以上。

原胶原的一级结构的主要特征是:约1/3是Gly(33%),Pro含量也很高(约12%),但Tyr含量少,Trp和Cys缺乏;具有三种修饰的氨基酸,即4-羟脯氨酸(Hyp)、3-羟脯氨酸(约9%)和5-羟赖氨酸(Hyl);每一条肽链都具有三肽重复序列模体——(Gly-X-Y)n,n约200。X和Y通常是Pro,也可能是Lys。Y位置上的Pro经常被羟基化为羟脯氨酸,Lys也常被羟基化成羟赖氨酸。

胶原蛋白富含 Gly 和 Pro 的性质使得它难以形成 $\alpha$ 螺旋，而富含 Pro 又使其难于形成 $\beta$ 折叠，但有规律的三联体重复序列却有利于 3 条 $\alpha$ 链相互“抱成一团”，形成另外一种螺旋，即三股螺旋（triple helix）（图 4-7）。三股螺旋为原胶原特有的二级结构，其二面角 $(\Phi, \psi)$ 为 $(-51^{\circ}, +153^{\circ})$ ，由三股以左手螺旋存在的 $\alpha$ 链组成，这三股 $\alpha$ 链以氢键相连，并相互缠绕形成右手超螺旋。在螺旋中，体积最小的 Gly 正好位于螺旋的内部，构成紧密的疏水核心，而 Pro 和 Hyp 的侧链位于三股螺旋的表面，面向外，以尽量减少空间位阻。每一个 Gly 残基的氨基 H 与 X 残基的羰基 O 形成氢键。三股螺旋比 $\alpha$ 螺旋更为伸展，每一个氨基酸残基上升 0.29 nm，一圈有 3.3 个氨基酸残基。

Pro 残基缺乏氢键供体, 因此单凭 3 条肽链主链之间形成的氢键, 还不足以稳定三股螺旋结构。这就需要通过特殊的化学修饰在肽链上引入额外的氢键供体。这种化学修饰就是主要发生在 Pro 残基上的羟基化反应。其中催化羟化反应的羟化酶 (hydroxylase) 需要 $\mathrm{O}_{2} 、 \alpha-$ 酮戊二酸、 $\mathrm{Fe}^{2+}$ 和维生素 C。 $\mathrm{O}_{2}$ 在反应中会将 1 个 O 转移给羟基, 另 1 个 O 需要 $\alpha-$ 酮戊二酸帮助处理。 $\mathrm{Fe}^{2+}$ 位于羟化酶的活性中心, 所起的作用是活化充当底物的 $\mathrm{O}_{2}$ , 但它很容易被氧化成无活性的 $\mathrm{Fe}^{3+}$ 。维生素 C 所起的作用是作为抗氧化剂, 可防止 $\mathrm{Fe}^{2+}$ 的氧化。故维生素 C 的缺乏会导致胶原的羟化反应不能充分进行, 也就影响到正常胶原原纤维的形成。那些非羟化的前 $\alpha$ 链在胞内很容易降解, 从而导致牙龈出血、创伤不易愈合等病变, 严重可发展为坏血病 (scurvy)。

胶原蛋白主要由成纤维细胞(fibroblast)合成。刚刚翻译出来的多肽链为前 $\alpha$ 链，其两端各有1段不含三肽重复序列的前肽，但却含有Cys。3条前 $\alpha$ 链的C端前肽借助Cys之间的二硫键形成链间交联，使得3条前 $\alpha$ 链“对齐”排列，然后从C端向N端形成三股螺旋。前肽部分呈非螺旋卷曲，形成球状结构域。带有前肽部分的胶原分子被称为前胶原(procollagen)。前 $\alpha$ 链在细胞内合成后还要进行糖基化(glycosylation)修饰,才能自组装成三股螺旋。

前胶原分泌到胞外以后，在前胶原肽酶（procollagenpeptidase）的催化下，两端的前肽序列被切除后成为原胶原。

在胞外基质内,4个原胶原分子以平行交错的方式聚合成胶原原纤维,再进一步包装成胶原纤维。原胶原分子内部和原胶原单位之间会逐步形成特殊的共价交联,进一步稳定和加强胶原结构。其中最常见的一种共价交联的形成需要胞外基质中的赖氨酰氧化酶(lysyl oxidase)。在此酶的催化下,原胶原上的Lys残基被氧化成醛赖氨酸(allysine)。而醛赖氨酸上的醛基可以与邻近肽链上的Lys氨基或Hyl的羟基缩合,由此形成共价交联。共价交联的形成是一个缓慢的过程,可持续一生,故交联的程度随着年龄的增加而加深。引入共价交联能提高组织强度,但同时也降低了组织的弹性和柔韧性。

## 二、球状蛋白质的结构与功能

球状蛋白质结构紧密,呈球状,长/宽≤3,溶于水,如血红蛋白和胰岛素等。机体内有各种各样的球状蛋白质,这里只选择两类与人体健康有密切关系的蛋白质——珠蛋白家族(globin family)和免疫球蛋白为例,详细分析它们的结构与功能之间的关系。

## （一）珠蛋白家族

光合有机体在地球上的出现为大气带来了氧气,而氧气的作用大大地推动了地球上生物的进化,因为富能生物分子通过有氧代谢可释放出更多的能量,产生更多的 ATP。例如,1 分子葡萄糖在无氧条件下分解,只能为细胞产生 2 分子 ATP,但在有氧条件下彻底分解,可为细胞产生 30~32 分子的 ATP。然而,生物在利用氧气的时候,会遇到一个麻烦,就是氧气的水溶性较差。为了解决这个问题,生物进化出一类特殊的蛋白质——珠蛋白家族来运输或贮存氧气。这一家族的蛋白质都含有血红素辅基(heme),能可逆地结合氧气,都含有珠蛋白折叠这样的结构模体。属于这一类家族的蛋白质有:肌红蛋白(myoglobin,Mb)、血红蛋白(hemoglobin,Hb)、神经珠蛋白(neuroglobin,Ngb)、细胞珠蛋白(cytoglobin,Cygb)、雄珠蛋白(androglobin)和豆血红蛋白(leghaemoglobin,legHb)等,其中肌红蛋白和血红蛋白存在于绝大多数脊椎动物体内,只有一些生活在南极水域的冰鱼(icefish)缺乏。至于 legHb,仅存在于豆科植物的根瘤中,它与氧气结合以后可为固氮菌胞内的固氮酶创造无氧的环境,因为固氮酶只有在无氧的条件下才能催化反应。

## 2. 血红蛋白

Hb 主要存在于红细胞, 其主要功能是作为 $O_{2}$ 的运输者, 为整个机体运输 $O_{2}$ 。除了红细胞, 机体内还有一些细胞可以表达少量的 Hb, 例如黑质 (substantia nigra) 内的 A9 多巴胺能 (dopaminergic) 神经元、巨噬细胞、肺泡细胞 (alveolar cell) 和肾脏的血管系膜细胞 (mesangial cell) 等。这些细胞表达的 Hb 的功能与运输 $O_{2}$ 无关, 而是作为一种抗氧化剂以及调节胞内铁的代谢。

Hb 由 4 个亚基组成, 因而有四级结构。每一个亚基就是 1 个珠蛋白, 单个亚基的一级结构与 Mb 差别较大, 只有 27 个位置的氨基酸残基与 Mb 相同, 但二级和三级结构却与 Mb 十分相似(表 4-1 和图 4-13)。

$O_{2}$ 的亲和力而言,4 价的 Hb 还不如 1 价的 Mb。Hb 的氧合曲线之所以为 S 形,是因为 Hb 与 $O_{2}$ 的结合具有正协同效应。

Hb 的正协同效应是指 Hb 分子有 1 个亚基结合 O₂ 后, 其构象会发生变化, 使得其他 3 个亚基在后面与 O₂ 结合的亲和力越来越高! 协同效应可使用齐变或序变模型来解释(参见第十三章 “酶活性的调节”)。两种模型都假定 Hb 存在两种构象: 一种是与 O₂ 结合亲和力低的紧张态 (tense state, T 态), 另一种是与 O₂ 结合亲和力高的松弛态 (relaxed state, R 态)。在没有结合 O₂ 时, Hb 的 4 条肽链之间结合紧密, 此时 Hb 主要以 T 态存在。这种紧密结合是由盐键以及结合在 2 条 β 链之间缝隙中的甘油酸-2,3-二磷酸 (2,3-bisphosphoglycerate, 2,3-BPG) 造成的, 它们屏蔽了分子表面疏水的空穴, 使得 Hb 结合 O₂ 的能力降低(单独的 α 链和 β 链结合氧气的能力与 Mb 相同)。

在脱氧状态下，Hb 各亚基上的 $Fe^{2+}$ 由于邻近 His 残基和吡咯环 N 原子之间的空间位阻，而略偏离血红素平面（0.04 nm）。然而，一旦有一个氧合，这个血红素 $Fe^{2+}$ 就移向卟啉环，致使 $O_{2}$ 能更好地结合。 $Fe^{2+}$ 的移位将近端 His 拉向血红素，近端 His 的移动又带动 F 螺旋移动，而 F 螺旋的移动势必影响到它与相邻亚基的 C 螺旋之间的相互作用，最终导致相邻亚基的构象发生改变。这真可谓“牵一发而动全身”！于是，相邻肽链之间的盐键遭到破坏，Hb 的四级结构也随之改变。这时 2 个二聚体（ $\alpha\beta$ ）之间发生滑移，移动 $15^{\circ}$ ，将 2,3-BPG 挤出。随后，四级结构发生进一步的变化，每条肽链表面的疏水空穴都暴露在外，这时的 Hb 主要以 R 态存在，于是结合 $O_{2}$ 的能力变强了（图 4-15 和图 4-16）。

$O_{2}$ 排 $CO_{2}$ ，而其他地方（如肌肉组织）吸 $CO_{2}$ 排 $O_{2}$ 。产生波尔效应的原因是 $H^{+}$ 和 $CO_{2}$ 能够与 Hb 特定位点结合，而促进 Hb 从 R 态转变为 T 态。

与 $\mathrm{H}^{+}$ 引发的波尔效应相关的基团有： $\alpha$ 亚基的N端氨基、 $\alpha$ 亚基的His122咪唑基以及 $\beta$ 亚基的His146咪唑基。这3个基团在Hb处于T态的时候都是高度质子化的，而当 $\mathrm{O}_{2}$ 与Hb结合以后， $\mathrm{H}^{+}$ 即发生解离。如果溶液中的pH下降，将有利于这3个基团处于质子化状态，从而稳定T态，抑制 $\mathrm{O}_{2}$ 的结合。用反应式来表示，即为： $\mathrm{Hb} + 4\mathrm{O}_2 \Leftrightarrow \mathrm{Hb(O_2)}_4 + n\mathrm{H}^+$ 。显然 $\mathrm{H}^{+}$ 浓度升高，会使反应平衡向左移动，这时有利于Hb释放结合的 $\mathrm{O}_{2}$ 。

$\mathrm{CO}_{2}$ 可通过两种途径产生波尔效应。这两种途径既有助于 $\mathrm{CO}_{2}$ 进入肺部被呼出体外，也有助于 $\mathrm{O}_{2}$ 在外周组织的释放。第一种是在碳酸酐酶（carbonic anhydrase）的催化下，红细胞内的 $\mathrm{CO}_{2}$ 发生反应： $\mathrm{CO}_{2} + \mathrm{H}_{2}\mathrm{O} \rightleftharpoons \mathrm{H}_{2}\mathrm{CO}_{3} \rightleftharpoons \mathrm{H}^{+} + \mathrm{HCO}_{3}^{-}$ 。此反应释放出的 $\mathrm{H}^{+}$ 可产生波尔效应，同时产生的 $\mathrm{HCO}_{3}^{-}$ 进入血浆，随循环到达肺部；第二种是 $\mathrm{CO}_{2}$ 与 $\mathrm{Hb}$ 的 N 端氨基可逆地反应： $\mathrm{CO}_{2} + \mathrm{Hb}-\mathrm{NH}_{2} \rightleftharpoons \mathrm{H}^{+} + \mathrm{Hb}-\mathrm{NH}-\mathrm{COO}^{-}$ ，形成氨基甲酸血红蛋白（carbaminohemoglobin），也释放出 $\mathrm{H}^{+}$ ，这对波尔效应也有贡献。但更重要的是，此反应可导致在 $\alpha$ 和 $\beta$ 亚基之间形成新的盐键，而有助于 $\mathrm{Hb}$ 处于 T 态，使其更容易将结合的 $\mathrm{O}_{2}$ 释放出来。

$CO_{2}$ 主要通过这两种途径进入肺，分别约占 88% 和 7%，大概只有 5% 的 $CO_{2}$ 以溶解的形式随循环进入肺。在肺部，较高的氧分压使得 Hb 能够有效地结合 $O_{2}$ ，而正协同效应使得 Hb 从 T 态变成 R 态，并释放出 $H^{+}$ 。同时，与 Hb 氨基端结合的 $CO_{2}$ 也被释放出来。释放出的 $H^{+}$ 与随血液循环到达肺部的 $HCO_{3}^{-}$ 在碳酸酐酶的催化下，发生逆反应，产生 $CO_{2}$ 和 $H_{2}O$ 。 $CO_{2}$ 随后通过呼气排出体外。

## （3）别构效应

别构效应是指除 $O_{2}$ 以外的各种配体在血红素铁以外的位点与 Hb 可逆结合，导致 Hb 的构象发生变化，进而影响到 Hb 氧合能力的现象。哺乳动物体内能与 Hb 结合的配体有 $H^{+}$ 、 $CO_{2}$ 、2,3-BPG 和 NO，它们统称为别构效应物（allosteric effector）。 $H^{+}$ 和 $CO_{2}$ 产生的效应就是波尔效应。2,3-BPG 产生的别构效应也是增强 Hb 在外周组织释放 $O_{2}$ 的能力。

胎儿血红蛋白(fetal hemoglobin, HbF)的肽链组成是 $\alpha_{2}\gamma_{2}$ ，无 $\beta$ 亚基，它与 $O_{2}$ 的亲和力明显高于成人的血红蛋白(adult hemoglobin, HbA)，这显然有利于胎儿通过胎盘(氧分压大大低于肺)从母亲那里获取 $O_{2}$ 。HbF 与 $O_{2}$ 亲和力之所以高于 HbA，是因为与 $\alpha$ 亚基结合的 $\gamma$ 亚基很难结合 2,3-BPG。由此可见，无私的母爱在分子水平上已经开始了！

不是所有的动物都使用 2,3-BPG 来降低 Hb 与 $O_{2}$ 的亲和力。例如，鱼类使用 ATP 和 GTP 来结合 Hb，以稳定它的 T 态构象，从而降低它与 $O_{2}$ 的亲和力。但在缺氧的条件下，鱼类红细胞内的 ATP 和 GTP 水平下降，这又提高了 Hb 与 $O_{2}$ 的亲和力。

至于 NO 对 Hb 结构与功能的影响,那是 Hb 在氧合状态下,NO 可与其特定位置的 Cys 侧链上的巯基结合,形成 S-亚硝基硫醇(S-nitrosothiol)。而一旦 Hb 释放 $O_{2}$ ,NO 就立刻解离到外周组织,通过扩张血管,有助于 $O_{2}$ 在局部的运输。

## Box4-1 难以置信的骆驼和鲨鱼的小抗体的发现及其巨大的应用前景

大多数动物产生的抗体与在我们人体产生的抗体一样大,具有2条重链(H链)和2条轻链(L链)。然而,骆驼和鲨鱼及其近亲制造的抗体要小,无L链,自上世纪80年代后期被发现后,就吸引了很多人的注意,因为它们可以锁定目标抗原分子的隐藏部位,进入人类抗体无法进入的不同蛋白质的小角落和缝隙中,更深入地穿透组织,而且大批量生产更便宜。所有这些特性使它们有望用于治疗多种疾病。另外,在诊断癌症等疾病方面也可派上用场,并且正在成为其他类型研究的关键工具。那么,这类小抗体是如何被发现的呢?还有就是究竟有什么特别的用途呢?另外在进化上,这些生物为什么会选择无L链的小抗体呢?

关于小抗体的发现,要归于一次抽血的运气。早在1989年,一群比利时布鲁塞尔自由大学生物学专业的学生需要一些血液来进行实验考试,他们的任务是将血液中的抗体形成Y形的2条H链和位于Y形顶部两侧的2条L链分开。

考虑到当时对潜在的 HIV 暴露感染的担忧,使用人类血液似乎风险太大,而且学生们也不愿意去杀死老鼠采血。碰巧的是,当时他们的指导老师 Raymond Hamers 教授正在研究骆驼的昏睡病。于是, Hamers 教授给学生们提供了一些现成的骆驼血。

奇怪的是,学生们在骆驼血液中只发现了抗体的 H 链。于是,每个学生都认为,要么骆驼抗体降解了,要么实验做错了。为了确定是不是抗体发生了降解,Hamers 教授特地去了安特卫普动物园采集了新鲜的骆驼血,结果确定了骆驼的抗体仍然只有 H 链。

几年后,另一组研究人员报告说,鲨鱼也产生只有 H 链的抗体,而且这些抗体的尖端所在的片段被称为可变新抗原受体(variable new antigen receptor, VNAR)。于是,骆驼和鲨鱼拥有无 L 链的小抗体终成定论。

对于小抗体的应用,实际上 Hamers 教授在发现它们的时候,就意识到了其潜在的用途。1993 年,Hamers 教授的团队在 Nature 上发表了这一发现,第二年就获得了这些骆驼抗体生产的专利,它们被称为 VHH 抗体或 “纳米抗体”。

所有抗体,无论是来自人类还是鲨鱼或骆驼,都在尖端具有V区,但在标准抗体中,可变区(V区)成对出现,分别来自H链和L链,V区上有互补性决定区(complementarity determining regions,CDR),与抗体特异性的识别抗原相关。然而,缺乏L链的骆驼和鲨鱼的抗体只有H链的V区,而这个V区带有一个超长的指状延伸,称为CDR3环。CDR3环被发现很容易采取不同的形状,并刺入人类抗体无法到达的地方(图4-22)。研究人员将这种特征描述为“分子瑜伽”。这意味着带有它的小抗体可以进入狭窄的地方,无论是身体组织还是单个分子的微小部位。

到了 2013 年, Hamers 教授申请的专利保护到期了, 于是全球进行小抗体的研究开始激增。从那以后, 科学家们对这些小抗体的优势有了更多了解。例如, 小抗体在室温下是稳定的, 因此无须将它们保存在冰箱中或冷藏运输, 而鲨鱼的小抗体甚至可以煮沸而不影响它们的功能。

2021 年, Hamers 教授在一次国际动物学年会上详细介绍了小抗体的无数用途, 而且与人体或小鼠的抗体一样, 小抗体还可以进一步缩小——只要保留 Y 构象的尖端即 V 区, 它是任何抗体的功能端, 就可以粘住病原体或毒素作为抗原的那一部分。

这些小抗体还倾向于正确地自组装，保持正确的构象，但全尺寸抗体具有更多肽链，因此容易错误折叠，而错误折叠可能会暴露更容易被免疫系统识别为外来分子的部分，这会在体内引起不好的免疫反应，对患者健康造成潜在的不良后果。

对这些不寻常的小抗体的研究现在开始取得成果。2019年，首个获得美国FDA批准的小抗体药物Cablivi上市。它用于治疗一种导致小血管凝块的罕见血液病。该疗法使用纳米抗体与血小板中的一种蛋白质结合，从而阻止它们粘在一起。

全尺寸抗体早已经用于癌症免疫治疗，不过，显然小抗体也可以做到，而且小抗体也不太可能引发不良的免疫反应，这可能会导致治疗效果显著改善。

小抗体还可以帮助医生更容易检测癌症，更精确地查明患病细胞。例如，通过将放射性示踪分子引入寻找癌细胞的特定抗体上，医生可以通过正电子发射计算机断层扫描（positron emission tomography, PET）定位癌细胞，显然小抗体要比标准抗体具有更高的分辨率，因为它们可以更深入地渗透到组织中。一个研究团队在2019年的P.N.A.S.上报告说，一种基于纳米抗体的示踪剂以比传统成像更高的特异性检测了小鼠体内的几种肿瘤。

另外,只需一颗简单的药丸,就可以将小抗体直接输送到肠道,这有助于阻止通过消化道进入人体的多种病原体,如轮状病毒。细菌、酵母和藻类等小型微生物无法有效地制造全尺寸抗体,因为它们太复杂了。然而,研究人员提出了使用基因工程螺旋藻或乳酸杆菌等无害细菌,通过药丸递送治疗性纳米抗体,这比生产药物更具成本效益。

小抗体对于研究蛋白质之间以及蛋白质与其他分子间的相互作用也很有帮助。例如，有研究人员解析了一种名为 ASIC1a 的人类蛋白质的结构——它形成一种让钠进入神经细胞的通道，并在痛觉和多种神经退行性疾病中发挥重要作用。该研究团队于 2021 年在 eLife 上报告说，用纳米抗体稳定蛋白质使研究人员能够以更高的分辨率确定其结构。

科学家们甚至正在研究它们在大脑中的潜在用途,这可是一项棘手的任务,因为血脑屏障喜欢将外来分子拒之门外。但已有人成功使用纳米抗体作为传感器研究了小鼠大脑中的一种蛋白质是否被激活,以及它的位置。

小抗体虽然非常有用,并且与其他抗体相比具有显著优势,但由于接触制造它们的动物的机会有限,它们仍然有点小众,并不是每个研究人员都有机会接触骆驼、美洲驼或者鲨鱼。但随着兴趣的增加,这种情况开始发生变化。研究人员还在开发新方法,例如创建合成纳米抗体和开发具有“骆驼化”免疫系统的小鼠用于研究。

在进化上,科学家们仍然不知道为什么骆驼科动物和软骨鱼类,如鲨鱼,是唯一已知能产生重链抗体的动物。

鲨鱼是依赖抗体作为免疫系统一部分的最古老的生物,它们的抗体比骆驼科动物的抗体更稳定。科学家推测,鲨鱼之所以依赖这类抗体,是因为它们血液中的尿素浓度很高,这会让大多数哺乳动物的抗体失活。

骆驼的进化比鲨鱼晚了约3.5亿年，但骆驼科动物的小抗体也相对古老：它们存在于旧大陆（如骆驼）和新大陆（如美洲驼和羊驼）的骆驼科动物中，这表明抗体可能早于“血统”的演变。也许，骆驼科动物某些特有的病原体最适合用小抗体来对付。

## 三、膜蛋白的结构与功能

细胞内有 1/3~1/2 的蛋白质属于膜蛋白。生物膜的各项功能主要是由各种结构不同的膜蛋白完成的。根据与膜结合的方式，膜蛋白可分为外在蛋白、内在蛋白和脂锚定蛋白。其中，外在蛋白也称为外周蛋白，它们主要靠极性的化学键（氢键和离子键）与膜表面结合，是可溶性的，因此可通过比较温和的方法，如改变离子强度或 pH，将它们与膜分开，在结构上与球状蛋白质非常相似，如细胞色素 c。至于内在蛋白，也被称为整合蛋白，它们镶嵌在膜上，与膜融为一体，主要通过非极性的疏水键与膜结合，因此需要通过比较剧烈的手段，如使用有机溶剂或去垢剂，才能将它们从膜上抽取出来，在结构和功能上更为复杂。脂锚定蛋白通过与其共价连接的疏水基团锚定在膜上（见第十七章“脂质”）。

膜内在蛋白镶嵌于膜脂的特性,使它们经常位于细胞与外部环境的交界处,适合行使介导细胞与环境之间的信号转导,以及跨膜转运各种水溶性物质等重要功能。例如,各种水溶性激素的受体以及各种跨膜的离子通道及转运蛋白都属于内在蛋白。然而,内在蛋白的高度疏水性使它们需要与膜共同形成稳定的天然构象,这就大大增加了研究的难度。

与研究球状蛋白质一样,要真正地理解膜蛋白的功能,首先需要确定它们的三维结构。然而,研究膜内在蛋白的三维结构并非易事,其主要困难集中反映在以下三个方面。

(1) 含量低。例如一些跨膜受体蛋白的含量为微克 ( $\mu g$ ) 级, 而应用基因工程方法大量表达膜内在蛋白也存在着很大的困难。因此, 迄今为止精细结构已被解析的膜内在蛋白主要是天然含量本来就高的, 如牛心线粒体细胞色素 c 氧化酶、细胞色素 $bc_{1}$ 复合体、植物光合作用的捕光复合体、紫色细菌光合反应中心、嗜盐菌菌紫红质和细菌膜孔蛋白等。

（2）分离、纯化比较困难。只有用较剧烈的条件(如去垢剂、有机溶剂和超声波)才能将它们溶解下来,而分离后一旦除去去垢剂或有机溶剂,它们很容易聚合为不溶物。

（3）分子量比较大，结晶也困难。分子量大的特性限制了 NMR 的使用，而难于结晶又限制了使用 X 射线晶体衍射对其结构的解析。

不过,随着冷冻电镜和 AI 技术的发展,现在对于膜内在蛋白的研究变得越来越容易。例如使用冷冻电镜技术,一大批以前难以研究的膜蛋白的三维结构纷纷被解析出来,例如人细胞的葡萄糖转运蛋白和钾离子通道等。

对已获得三维结构的各种膜内在蛋白的研究表明,它们与非膜蛋白一样,含有相同的二级结构元件,但由于几乎完全存在于由膜脂疏水尾形成的疏水环境之中,因此需要解决肽键的亲水性质造成的将一条多肽链插入或贯穿在一个脂双层膜上能量不利的问题。

要解决多肽链通过脂双层膜能量不利的问题,最简单的方法是形成疏水 $\alpha$ 螺旋,因为 $\alpha$ 螺旋满足了主链亲水部分形成氢键的倾向,并使疏水侧链面向脂环境。既然 $\alpha$ 螺旋的每一个残基延伸 0.15 nm,那么一个跨膜 $\alpha$ 螺旋约含 20 个氨基酸残基,这相当于脂双层疏水部分的平均厚度,即 2.5~3 nm(图4-24)。因此,一段由 20 个疏水氨基酸构成的 $\alpha$ 螺旋就足以横跨生物膜,此数据实际上已成为鉴别一种蛋白质是不是膜内在蛋白的一个重要标志。

还有一种方法,可以解决多肽链通过脂双层膜遇到的能量不利的问题,那就是形成β折叠。然而,膜蛋白中的β折叠单凭序列是难以确定的,原因是1个跨膜的β股只需要8~9个氨基酸残基就够了,但折叠一般由亲水和疏水氨基酸交替组成。到目前为止,发现的全β折叠膜蛋白具有反平行的β折叠桶结构,例如孔蛋白。联系相邻β股的是短的亲水性转角。

孔蛋白主要存在于革兰氏阴性菌、线粒体和叶绿体的外膜上,其中央通常是一个由 $\beta$ 折叠桶构成的孔洞(见上一章图 3-18),允许小分子和水被动扩散进入周质。孔洞的两侧交替分布着带正、负电荷的残基,以创造跨膜的电场,使不同的孔蛋白对离子具有不同的选择性。

细菌的孔蛋白都是三聚体,有很大的表面区域被包埋在亚基之间,这与球状蛋白质亚基之间被包埋的表面并无两样。面向脂双层的表面高度疏水,比蛋白质的内部和亚基之间界面上的疏水性要高得多。

总之，多肽链总是通过形成特殊的二级或三级结构来避免肽键与疏水的脂环境接触，以便插入到膜的内部。实际上，疏水环境更有利于二级结构的形成，这是因为在疏水环境中没有水分子的竞争干扰，肽链主链上的氢键更容易形成。

总之，就氨基酸分布而言，膜内在蛋白暴露在水相中的表面性质实际上与一般的球状蛋白质相同，它们的差别主要在于与脂双层作用的氨基酸的性质和分布。如果不考虑与脂双层相互作用的表面，膜内在蛋白的内部与绝大多数球状蛋白差不多，但那些参与信号转导的离子通道或参与物质跨膜转运的孔蛋白除外。

## 四、天然无折叠蛋白质的结构与功能

前面所述的各种蛋白质,无论是纤维状蛋白质,还是球状蛋白质或膜蛋白,由于具有特定的三维结构,才具有特定的生物学功能。一旦失去了特定的结构,成为松散无折叠状态,就立刻丧失功能。然而,自上世纪90年代初以来,人们开始发现越来越多的蛋白质,在生理条件下,尽管缺乏特定的二

迄今为止,已发现的 NUP 约占蛋白质总数的 30%。NUP 一般可分为两类(图 4-27):一类是完全无折叠蛋白质(fully unfolded protein),约占 10%;另外一类是部分无折叠蛋白质(partially

在天然无折叠蛋白质中,有些必须处在无折叠状态才具有一定的功能,有些需要跟特定的配体(经常是 DNA)结合,进而发生折叠,再行使功能。例如,淋巴类增强子结合因子 1(lymphoid enhancer-binding factor-1, LEF-1) 就属于后一类,它在 B 细胞前体和 T 细胞中表达,定位在细胞核,与 DNA 分子上的 T 细胞受体- $\alpha$ 增强子(T-cell receptor-alpha enhancer)结合以后发生折叠,然后刺激相关基因的表达。再如,真核细胞中有两种转录因子,一是 CREB 结合蛋白(CREB-binding protein),它有一个结构域叫细胞核辅助激活蛋白结合结构域（nuclear co-activator binding domain, NCBD），该结构域最初为熔球态，另一个是甲状腺素和视黄酸受体的辅助激活蛋白（co-activator for thyroid hormone and retinoid receptors, ACTR），它带有一个完全无序的激活结构域。研究表明，一旦这两个转录因子的这两个结构域结合，则立刻折叠（图4-28）。

NUP 的主要功能是参与信号转导、细胞周期调控和基因表达调控,此外,它与翻译后加工也有关系,还经常充当 RNA 和蛋白质的分子伴侣。

## Box4-2 生化新发现——天然无折叠蛋白质的新功能

有一类显微生物,叫缓步动物(tardigrade)或水熊虫(water bear),其生存能力超强,从高山到深海,几乎无处不在(图4-29)。虽然它们在适宜的环境下平均寿命仅有几个星期到几个月,但在干燥缺水的环境下却可以生存好多年,甚至长达一个世纪。对此,生物学家一直在试图揭示水熊虫顽强生存的秘密,尤其是它们的“泡发”过程:在极端干旱的条件下,水熊虫身体开始皱缩,进入干化(desiccation)状态,这时细胞几乎完全脱水,体内的代谢率下降到正常水平的0.01%。在此阶段,水熊虫几乎“无所事事”,仅仅是活着,但却还能抵抗真空、高压和高温的折磨。然而,一旦接触到水,水熊虫就像重新浸湿的海绵一样,其生命活动又会完全恢复,好像什么都没有发生过。

在学习蛋白质折叠机制的时候,我们曾遇到过一类有悖“Anfinsen 法则”的蛋白质,叫天然无折叠蛋白或内在无序蛋白(IDP),它们在细胞内合成后并没有在疏水作用力的驱动下进行折叠。虽然有一些IDP 在遇到合适的配体以后,受到诱导,会迅速折叠并行使它们的功能,但也有 IDP 似乎永不折叠,对于这些蛋白质究竟在体内能行使何种功能一直不很清楚。

现在有人在水熊虫体内,发现一类 IDP 似乎赋予了这类生物超强的抗旱能力。根据美国北卡罗来纳大学 T. C. Boothby 等人 2017 年 2 月 18 日发表在 Molecular Cell 上题为 “Tardigrades use intrinsically disordered proteins to survive desiccation” 的研究论文,在脱水状态下,水熊虫细胞开始上调水熊虫特有的内在无序蛋白 (tardigrade-specific intrinsically disordered protein, TDP) 的表达,这样可以给胞内其他重要的生物分子,比如其他蛋白质,筑起一层玻璃状的保护壳,直至脱水状态解除。

这些 TDP 在缺水的条件下更难折叠,但却充当了“金钟罩”,保护着水熊虫细胞。其他生物可使用海藻糖(trehalose)来对付干旱,即大量合成这种寡糖来取代细胞的内容物,并严格限制细胞残留的水分子,阻止它们快速膨胀而丧失。多年来,研究者以为水熊虫也是这样。然而,许多水熊虫只合成少量海藻糖。因此,这些水熊虫很有可能通过 TDP 起作用,达到海藻糖同样的效果。为了证明这一点,Boothby 及其同事使用了 RNA 干扰技术,将编码 TDP 的基因进行了敲减,结果发现,水熊虫在干旱脱水环境下的生存能力明显下降。TDP 可能单独作用,也可能和体内少量的海藻糖一起,在干燥的细胞体内形成非晶态固体(non-crystalline amorphous solid), 即玻璃体。这个玻璃金钟罩将一些重要生物分子, 比如其他蛋白质包裹住, 防止它们变性和分解。因此, 在水熊虫干燥的进程中, TDP 充当了一种功能性调节物, 帮助水熊虫细胞在玻璃化状态和遇水复苏状态间切换。

为了测试水熊虫的 TDP 在其他生物中的表现,他们将一种 TDP 基因导入到细菌和酵母中表达。结果显示,细菌和酵母的抗干旱能力都得以大幅提高,其中的一些酶也更耐旱了。这证明了水熊虫抗干旱的“祖传秘方”也可以被其他生物借用。因此,将来完全有可能借助于 TDP 来提高其他生物的抗干旱能力,还可以实现对植物和动物进行安全的脱水处理。

## 第四节 蛋白质功能预测

就目前的研究水平,蛋白质的生化功能已经可以从它的序列和结构推导出来,而在当今的基因组学和后基因组学时代,功能通常凭经验,再综合各种不同的技术也可以得到。尽管预测一种蛋白质功能最好的方法是先得到它的三维结构,但也可以单独进行功能预测或者与结构预测结合起来。

目前经常使用的功能预测途径包括以下六种。

## 1. 基于序列的途径(sequence-based approach)

该途径的原理是:若蛋白质 A 有功能 X,而蛋白质 B 是蛋白质 A 的同源物,那 B 就有功能 X。虽然序列比对是检测同源蛋白的强有力工具,但是限于亲缘关系不太远的基因组。

## 2. 基于结构的途径（structure-based approach）

该途径的原理是:若蛋白质 A 有功能 X,而且具有某种结构特征,那 A 的功能位点便具有这种结构特征;若蛋白质 B 也具有这种结构特征,那蛋白质 B 就可能具有功能 X。

这种途径可能检测出前一种途径不能确定的遥远的同源物。

## 3. 基于结构与序列比对的途径

该途径除了使用序列信息,还使用结构信息。其中,蛋白质结构预测线索法(protein threading)较为流行。这种方法首先假设多肽的构象,然后根据得到的结构计算能量。通过计算各种已知结构的能量,可以得出与给定蛋白质序列最符合的构象。在获得给定序列的蛋白质构象以后,需要利用一种叫 SCOP 分类数据库(http://scop.berkeley.edu/)的数据。

SCOP 数据库根据蛋白质的结构和功能的相似性, 将蛋白质分成若干个等级, 按照从低到高的排列依次是: 家族(family)、超家族(super-family)、栏(fold) 和类(class)。其中类是最高级水平, 现有 12 类, 包括全 $\alpha$ 蛋白(all-alpha protein)、全 $\beta$ 蛋白(all-beta protein)、 $\alpha/\beta$ 蛋白(alpha-beta protein)、 $\alpha+\beta$ 蛋白(alpha+beta protein)、多结构域蛋白(muti-domain protein)、膜和细胞表面蛋白及肽(membrane and cell surface protein and peptide)、小蛋白(small protein)、卷曲螺旋蛋白(coiled-coil protein)等; 栏为第二级水平, 现有 1485 个栏; 超家族位于第三级, 现有 2067 个超家族; 家族处于第四级, 现有 5084 个家族。

使用序列-结构比对途径,可以预测一种蛋白质属于哪一个家族、超家族或栏。被预测的处于同一个 SCOP 家族的蛋白质被认为是直向同源物;处于同一个 SCOP 超家族的蛋白质被认为是同源物;处于同一栏的蛋白质被认为是类似物。

通过这种途径,还可以对一种蛋白质的配体结合位点或大分子结合位点进行预测:已知约85%的配体结合位点是最大的裂缝,还有约10%的配体结合位点是第二大裂缝;大分子结合位点(蛋白质、DNA和RNA)和无序区域之间有密切的关系,而蛋白质序列中属于无序区的残基可通过计算的方法预测出来。

## 4. 基于模体的途径 (motif-based approaches)

该途径的原理是:若一组蛋白质有功能 X, 并且它们都有模体 Y, 而蛋白质 A 具有模体 Y, 那蛋白质 A 的功能就可能与 X 有关。这种方法依赖于已鉴别的序列模体。Prosite 数据库（http://expasy.org/prosite）含有 1300 个以上的蛋白质家族特异性的序列模体。而 ScanProsite 允许扫描一个蛋白质序列，从而发现存储在 Prosite 中的模体和资料（profiles）。

Prosite 是第一个蛋白质序列二次数据库, 现由瑞士生物信息学研究所 SIB 维护。Prosite 数据库是基于对蛋白质家族中同源序列多重序列比对得到的保守性区域, 这样的区域通常与生物学功能有关, 例如酶的活性位点、配体或金属结合位点等。因此, Prosite 数据库实际上是蛋白质序列功能位点数据库。通过对 Prosite 数据库的搜索, 可判断该序列包含什么样的功能位点, 从而推测其可能属于哪一个蛋白质家族。

## 5. 基于“连坐”（guilt-by-association）的途径

该途径的原理是:若蛋白质 A 有功能 X,蛋白质 B 经常与蛋白质 A 相联系,那 B 的功能就可能与 X 相关。基于 “连坐” 的功能预测是一种非同源性途径。

## 6. 基于 AI 技术的途径

AI 技术的发展现在不仅让预测蛋白质的结构变得越来越容易、越来越精确(参见前一章有关 AlphaFold2 的内容介绍),也必将让预测蛋白质的功能变得容易和精确。例如,一家叫 Shiru 的公司最新推出了一组机器学习方法用来预测蛋白质亚细胞定位和功能。这种简单有效的方法结合了语言模型(LM)和图形神经网络(GNN),对蛋白质功能预测具有很大的潜力(https://www.proteinreport.org)。

## 科学故事——一种多功能蛋白质的发现

以前，在分子生物学中有一个基本法则，就是一个基因决定一条多肽链，而一条多肽链只具有一种功能。然而，随着分子克隆技术的发展，越来越多已知活性的蛋白质及其基因被克隆、测序和比对，在对许多结构分析后发现，蛋白质结构与活性之间已不再是单纯的一对一的关系了。1987年，芬兰Oulu大学的Taina Pihlajaniemi（图4-30）在研究人体胶原蛋白的时候，就发现了这样的例外。


4–30 Taina Pihlajaniemi


胶原蛋白是人体中含量最丰富的蛋白质,其二级结构是由三条相同的多肽链互相缠绕而形成的三股螺旋,每条肽链上含有多个 Gly-X-Y 重复序列,其中 X 位置主要是 Pro,Y 位置主要是羟脯氨酸 (Hyp)。

胶原蛋白三股螺旋结构的稳定性主要与 Y 位置上有多少脯氨酸被羟基化有关, 因此, 催化 Pro 羟基化的脯氨酸羟化酶是决定胶原蛋白稳定性的一个十分重要的酶。脊椎动物的这种酶是由 2 个 α 亚基和 2 个 β 亚基组成。α 亚基和 β 亚基分别由不同的基因编码。不论 α 或 β 亚基, 单独都没有活性, 但 β 亚基的单克隆抗体能使整个酶失去活性, 而只有 α 和 β 亚基同时存在的时候, 酶才能与它的辅因子——抗坏血酸结合, 这说明 β 亚基的确是表现酶活性的重要组成部分。但奇怪的是, α 及 β 亚基在细胞内的表达并不一致。β 亚基的数量远远高于 α 亚基, 因此, α 亚基合成后立刻会与 β 亚基结合, 形成有活性的脯氨酸羟化酶, 而留下许多单独存在的 β 亚基。那么单独的 β 亚基会有其他的功能吗?

既然蛋白质的一级结构决定蛋白质的三维结构，而蛋白质的三维结构又决定它的功能，那么如果知道了一种蛋白质的一级结构，就不仅可以预测和解释这种蛋白质的三维结构和功能，同时还可以将这种蛋白与其他已知功能的蛋白质进行序列比对，从而有可能发现新的功能。Pihlajaniemi在得到脯氨酸羟化酶β亚基的一级结构以后，便将它的氨基酸序列输入计算机，在互联网上和其他已知蛋白质的氨基酸序列进行比对。出乎意料的是，她发现人类脯氨酸羟化酶β亚基的氨基酸序列有 $94\%$ 与小鼠的蛋白质二硫键异构酶（PDI）相同。她用纯化的β亚基也检测到它的确有PDI的酶活性，再用克隆的β亚基的cDNA作探针，发现人类细胞中只有一个基因具有类似的碱基序列。因此PDI很可能就是脯氨酸羟化酶的β亚基。换句话说，一个基因表达出来的蛋白质在不同的条件下可以同时具有二种完全不同的酶

活性。

PDI 早在 1963 年就在鼠肝和胰腺组织中发现, 其主要功能是催化蛋白质上二硫键的交换反应, 具有较广的底物特异性。PDI 在体外能够促进被变性或还原的含有二硫键的蛋白质重获活性。当一个蛋白质的天然构象遭尿素破坏, 而其二硫键也被还原剂打破以后, 若要恢复这个蛋白质原来正确的构象, 不仅要除去尿素, 同时还要让二硫键重新形成, 并恢复到原来正确的连接, PDI 就可以加速这个 “尝试错误、发现正确” 的过程。但 PDI 在体内是否也扮演同样的角色则仍是未知数。有了这个后知之明, 再去看 PDI 在体内分布的情形, 发现 PDI 的活性主要集中在内质网, 这很容易让人们想起它可能在分泌蛋白折叠过程中起作用, 因为许多分泌蛋白都含有二硫键。而后来的许多研究证明, PDI 的确就具有这种功能。

那么， $\beta$ 亚基的功能是不是就到此为止了呢？1991年，Wetteran J.R.等人使用氨基酸序列分析和免疫化学分析，发现了一种由大小两个亚基组成的微粒体甘油三酯转移蛋白（microsmal triglyceride transfer protein, MTP）的小亚基与脯氨酸羟化酶的 $\beta$ 亚基一模一样。但MTP的PDI酶活性仅是自由PDI的十分之一。后来又有人发现，单独的 $\beta$ 亚基在细胞内还充当甲状腺素结合蛋白（thyroid hormone binding protein, THP）。

迄今为止，已经发现了许多多功能蛋白，像哺乳动物的位于细胞质基质的脂肪酸合酶居然具有7种酶活性，外加一种酰基载体蛋白的功能。多功能蛋白质的存在不仅可以提高基因的编码功能，还可能有利于对蛋白质基因的表达及其活性进行调控。
