# 第三章 蛋白质的结构

蛋白质是由多个氨基酸通过肽键连接而成的多聚物。其结构可被人为地划分为四个层次，即一级结构、二级结构、三级结构和四级结构，其中二级结构、三级结构和四级结构统称为高级结构。蛋白质的一级结构是由编码它们的基因的一级结构决定的，而蛋白质的高级结构又是由一级结构决定并通过折叠形成的。

本章将从肽和肽键谈起,重点介绍蛋白质各级结构的特征、多肽链的折叠机制以及测定和预测蛋白质结构的方法,同时会对蛋白质与蛋白质之间的相互作用以及蛋白质组和蛋白质组学的概念做简单的介绍。

## 第一节 肽

肽（peptide）就是氨基酸之间发生缩合反应以后通过肽键（peptide bond）或酰胺键（amido bond）相连的聚合物，它包括寡肽（oligopeptide）、多肽（polypeptide）和蛋白质。构成肽的每一个氨基酸单位称为氨基酸残基（residue）。各氨基酸残基以肽键相连形成的链状结构称为肽链（peptide chain）。

## 一、肽的分类和命名

肽的命名和分类的主要依据是氨基酸残基的数目、组成和排列顺序。

## （二）肽的序列写法

按照惯例,书写一条肽链的序列总是从 N 端到 C 端,即 N 端放在最左边,其编号为 1 号位,后面的氨基酸依次编号,C 端氨基酸残基放在最右边(图 3-2)。有时为了强调,可在 N 端和 C 端分别添加 H 和 OH,以此来突出两端游离的性质。各氨基酸残基可用三字母或单字母缩写表示。图 3-1 中的三肽可写为 Ser-Cys-Asn 或 H-Ser-Cys-Asn-OH 或 SCN。

## （三）肽的命名

寡肽通常根据氨基酸的排列顺序,从 N 端到 C 端,依次称为某氨酰、某氨酰……某氨基酸。按照上述规则,图 3-1 中的二肽和三肽应分别命名为丙氨酰天冬氨酸和丝氨酰半胱氨酰天冬酰胺。

多肽和蛋白质的命名一般是根据它们的来源或/和功能进行命名。如胰高血糖素是一种来源于胰岛、功能是升血糖的多肽，血红蛋白是来源于红细胞与运输氧气有关的蛋白质(参见 Box3-1)。

## 二、寡肽的理化性质

寡肽常见的理化性质包括手性、两性解离、双缩脲反应和水解。

（1）手性。该性质是由具有手性的氨基酸残基带来的。一种寡肽只要不是寡聚Gly，就具有手性，具有手性的寡肽自然就有旋光性。

(2) 两性解离。该性质是由肽链两端游离的氨基和羧基以及侧链带有解离性质的氨基酸残基带来的。对于解离基团较少的寡肽来说, 两性解离性质与游离的氨基酸相近, 例如滴定曲线。但随着可解离基团的增加, 滴定曲线会变得越来越复杂。如果一种寡肽拥有的可解离基团的 $\mathrm{p}K_{\mathrm{a}}$ 已知, 那么 $\mathrm{pI}$ 也可以通过理论计算求得。

（3）双缩脲反应。双缩脲在碱性溶液中能与硫酸铜反应生成紫红色络合物，此反应称为双缩脲反应（biuret reaction）。凡大于二肽的肽因为含有与双缩脲相似的2个肽键的结构，所以也能发生此反应。但二肽不行，因为它只有一个肽键。

(4) 水解。寡肽含有肽键,而肽键在特定的条件下会发生水解。

## Box3-1 生化点滴——五花八门的蛋白质命名方法

迄今为止，科学家们已发现几万种不同的蛋白质，而且每天都可能有新的蛋白质被发现。对于一种蛋白质的命名，生化界并没有一个统一的系统命名法则，主要是由发现者来定，而发现者命名的时候通常各行其是，随意性很强，这就让许多初学生化的人面对各种稀奇古怪的蛋白质的名字，如堕五里雾中。那么，蛋白质的命名究竟有没有什么规律呢？在这里，我想就这一个问题做一点总结。

如果一种蛋白质是酶,它的命名就很容易,只要按照酶命名的基本规则进行就可以了,如乙醇脱氢酶、胃蛋白酶和蛋白质激酶 A。

如果发现的蛋白质不是酶,命名的方法就主要有以下几种:(1)根据来源、性质、功能或者将来源与性质/功能相结合起来进行命名,如胰岛素、胶原蛋白、血红蛋白、肌红蛋白、孔蛋白(porin)、神经生长因子(nerve growth factor,NGF)、绿色荧光蛋白(green fluorescent protein,GFP)、枯草杆菌素、蓖麻毒素和霍乱毒素。在这些蛋白质中很多蛋白质的英文名称中有后缀——in,如胰岛素为insulin。“in”最初被翻译为素,但现在多被翻译为蛋白,如cyclin起初被翻译成周期素,但现在已统一为周期蛋白,不过有少数蛋白质的名字仍然带“素”,如泛素(ubiquitin)、瘦素(leptin)和肾素(renin)。(2)根据大小。一般用小写的p(protein)加上其大小来命名,大小的单位是千道尔顿(kDa)。例如,p53是一种重要的抑癌基因编码的抗癌蛋白,它在电泳时条带位置显示其大小为53 kDa。(3)根据结构特征。如网格蛋白(clathrin)、叉头盒O蛋白1(forkhead box O1,FOXO1)。(4)根据突变引起的疾病。例如,多种参与哺乳动物核苷酸切除修复的蛋白质突变可导致着色性干皮病(Xeroderma pigmentosum,XP),因此这些蛋白质用XP再加字母编号来表示,像XPA和XPC。(5)用英文缩写来表示,这是现在表示蛋白质的一种最简单的方法,相关缩写的字母通常都有一定的来源和意思。例如,参与信号转导的Sos蛋白最初在研究果蝇的一条信号通路中发现的,在一种叫sevenless基因的下游起作用,发现者把它比作是“son of sevenless”,故后来被称为Sos;Ras是指大鼠肿瘤病毒(rat sarcoma virus)编码的一种蛋白质;Rho是后来被发现的Ras的同源物(Ras homologue,Rho);Arf是一种ADP核糖基化因子(ADP-ribosylation factor,Arf);Sar是分泌相关联的Ras家族相关蛋白(secretion-associated and Ras superfamily-related protein);Ran是指Ras相关的RNA运输(Ras-related RNA transport,Ran);Rap是Ras相关蛋白(Ras-related protein,Rap),参与高尔基和内质网之间的小泡运输;Tau是微管蛋白相关蛋白(tubulin-associated unit),在中枢神经系统的轴突中维持微管的稳定;Cas是CRISPR相关蛋白(crispr-associated protein),作为原核生物特有的一种免疫系统中的重要成分。(6)根据发现者或神话中的人物来命名。例如,Kornberg酶是指Arther Kornberg发现的DNA聚合酶I,参与真核细胞双链断裂修复的Artemis蛋白根据是希腊神话中的月亮女神与狩猎女神——Artemis命名的。(7)由发现者随意命名。如周期蛋白(cyclin)是R. Timothy Hunt于1982年最初发现的,Hunt曾经说过之所以把这类蛋白质命名为cyclin,是因为他的爱好是cycling。再如,参与真核生物DNA双链断裂修复的Ku蛋白,发现者之所以这样命名,是因为它是在一位姓Ku的日本病人体内发现的。

这些五花八门的命名给学习带来了一定的困难,但我们能做的就是尊重发现者的权利,同时它也告诉每一个人,如果有谁想将来有机会用自己的方法来命名一种蛋白质,那就快点发现一种新的蛋白质吧!

## 第二节 蛋白质的各级结构

蛋白质是至少由 51 个氨基酸残基构成的肽。生物体内有各种各样的蛋白质,它们具有广泛的多样性,既有组成的多样性、大小的多样性,又有结构的多样性和功能的多样性。

蛋白质组成的多样性反映在两个方面:一是由几条肽链组成;二是有没有非氨基酸成分。从肽链的数目来看,有的蛋白质只有一条肽链,如肌红蛋白和胰核糖核酸酶,有的蛋白质不止一条肽链,如胰岛素和血红蛋白。从有无非氨基酸成分的角度来看,有的蛋白质只由氨基酸组成,不含其他化学成分,如胰岛素。这类蛋白质称为简单蛋白(simple protein)。有的蛋白质还含有非氨基酸成分,这类蛋白质被称为缀合蛋白(conjugated protein)。非氨基酸成分有四种形式:第一种是在氨基酸侧链上通过共价修饰引入的各种基团,如糖基、脂酰基、甲基和磷酸基团等;第二种是指与蛋白质结合的无机成分,通常是一些金属离子;第三种为辅酶(coenzyme),专指与蛋白质结合并不紧密的有机分子,如辅酶I和辅酶II;第四种为辅基(prosthetic group),专指与蛋白质紧密结合的有机分子,如FAD和FMN。后三种非氨基酸成分一般是相关蛋白质的功能所必需的,被统称为辅因子(cofactor)。

大小的多样性则反映在有的蛋白质较小,有的蛋白质则比较大。然而,机体内的蛋白质的大小通常是受到限制的,其主要原因是蛋白质越大,在合成的时候就越容易出错(参见第四十一章 “mRNA 翻译”)。

结构的多样性反映在不同的蛋白质在结构上,特别是在三维结构上不尽相同,如有的蛋白质呈纤维状,有的蛋白质呈球状,有的蛋白质与生物膜结合。总之,蛋白质结构的多样性最为重要,因为它直接决定了蛋白质功能的多样性。

为了方便起见,蛋白质的结构可分为四个层次,即一级结构(primary structure)、二级结构(secondary structure)、三级结构(tertiary structure)和四级结构(quartenary structure)(图3-3),但并不是所有的蛋白质都具有这四个层次的结构。

对于每一个层次的结构,我们至少需要从三个方面来认识:一是它的基本含义;二是稳定它的化学键;三是如何确定它。

## 一、蛋白质的一级结构

蛋白质的一级结构也叫蛋白质的共价结构,是指氨基酸在多肽链上的排列顺序。如果一种蛋白质含有二硫键,那么它的一级结构还包括二硫键的数目和位置。

稳定蛋白质一级结构的化学键就是肽键。肽键是两个相连的氨基酸残基中的一个羰基 C 与一个氨基 N 之间形成的共价键。肽链中的每一个酰胺基称为肽基（peptide group）或肽单位（peptide unit）。对肽键的研究表明，它具有以下几个重要的性质。

（1）具有部分双键的性质（40%），键长为 0.133 nm，短于一个典型的 CN 之间的单键，长于一个典型的 CN 之间的双键。肽键所具有的双键性质是氨基 N 上的孤对电子与相邻羰基之间发生共振作用造成的（图 3-4）。由于以单键为主（60%），因此肽键一般以羰基 C 与氨基 N 之间的一条短线表示。

根据惯例:如果肽链处于完全伸展状态,即所有的肽键位于同一个平面上, $\phi$ 和 $\psi$ 定为 $\pm180^{\circ}$ ; 如果 $\phi$ 的旋转单键 $C_{\alpha}-N1$ 两侧的 N1-C1 和 $C_{\alpha}-C2$ 呈顺式时,则规定 $\phi=0^{\circ}$ ; 如果 $\psi$ 的旋转键 $C_{\alpha}-C2$ 两侧的 $C_{\alpha}-N1$ 和 C2-N2 呈顺式时,则规定 $\psi=0^{\circ}$ ; 从 $C_{\alpha}$ 向 N1 观察,顺时针旋转 $C_{\alpha}-N1$ 键得到的 $\phi$ 角为正值,反之为负值; 从 $C_{\alpha}$ 向 C2 观察,顺时针旋转 $C_{\alpha}-C2$ 键得到的 $\psi$ 角为正值,反之为负值。

理论上， $\phi$ 和 $\psi$ 可以是 $+180^{\circ} \sim -180^{\circ}$ 之间的任意值，但由于主链上的原子和侧链基团之间存在空间位阻（steric hindrance），因此有些角度是不允许的，例如 $\phi$ 和 $\psi$ 不能为 $0^{\circ}$ 。据估计，蛋白质分子中能出现的二面角大约仅占理论值的 $10\%$ 。不同氨基酸残基的 R 基团不一样，由此产生的空间位阻也不一样。Gly 因为 R 基团最小，产生的空间位阻也就最小，与它相关的二面角变化的范围自然最大，而 Pro 的刚性吡咯环的存在让它的 $\phi$ 值被限制在 $-35^{\circ} \sim -85^{\circ}$ 之间。

## 二、蛋白质的二级结构

蛋白质的二级结构（secondary structure）是指多肽链不包括 R 基团的主链（backbone）部分在局部形成的一种有规律的折叠和盘绕，其稳定性主要靠主链上的氢键来维持。

常见的二级结构有 $\alpha$ 螺旋（alpha-helix）、三股螺旋（triple helix）（参见下一章有关胶原蛋白的内容）、 $\beta$ 折叠（beta-sheet）、 $\beta$ 转角（beta-turn）、 $\beta$ 凸起（beta-bulge）、环（loop）和无规卷曲（random coil）。其中前五种比较有规律，所涉及的肽段上的每一对二面角都差不多（表3-1），在Ramachandran图上，会集中在某一区域（图3-10），而环和无规卷曲的二面角则落在其他范围较广的允许区。从结构的稳定性上看，右手 $\alpha$ 螺旋 $>\beta$ 折叠 $>\beta$ 转角 $>$ 无规卷曲和环，但从功能上看，正好相反，酶与蛋白质的活性中心通常由无规卷曲和环充当， $\alpha$ 螺旋和 $\beta$ 折叠一般只起支持作用。

（4）螺旋的方向一般是右手，左手螺旋很少见。这是因为蛋白质分子只有L氨基酸，若形成左手螺旋，L氨基酸的β碳和羰基O在空间上容易发生冲突，其稳定性会降低。

（5）氨基酸残基的 R 基团伸展在螺旋的表面，虽不参与螺旋的形成，但其大小、形状和带电状态却能影响到螺旋能否形成以及形成后的稳定性。

可以使用由同一种氨基酸残基构成的多聚氨基酸(polyamino acids)，来研究一个氨基酸的R基团对α螺旋的形成及其稳定性的影响。例如，多聚Leu和多聚Ala很容易形成α螺旋，多聚Gly只会形成无规卷曲，多聚Pro不形成α螺旋，但会形成一种特别的右手螺旋( $\phi$ 和 $\psi$ 分别是 $-75^{\circ}$ 和 $+160^{\circ}$ ，肽键都为顺式)或左手螺旋( $\phi$ 和 $\psi$ 分别是 $-75^{\circ}$ 和 $+150^{\circ}$ ，肽键都为反式)。多聚Asp和多聚Glu在pH $\geqslant7$ 的时候，只会形成无规卷曲，但若pH<2.5，则自发地形成α螺旋。这是因为如果pH $\geqslant7$ ，Asp和Glu的R基团均带负电荷，静电的排斥导致主链无法形成稳定的α螺旋，但若pH<2.5，R基团质子化，不再带电荷，因此可以形成α螺旋。同理，多聚Lys在pH<11的时候，只形成无规卷曲，是因为R基团带正电荷，阻碍了α螺旋的形成，而如果pH $\geqslant12$ ，其R基团不再带有电荷，就很容易形成α螺旋。

一般而言,判断一种氨基酸残基是否有利于形成 $\alpha$ 螺旋,要看它的侧链能否保护螺旋在主链上的氢键。在 20 种常见的蛋白质氨基酸中,经常出现在 $\alpha$ 螺旋中的有 Ala、Cys、Leu、Met、Glu、Gln、His 和 Lys,特别是 Lys、Met、Ala、Leu 和 Glu。最常见的两种不利于形成 $\alpha$ 螺旋的氨基酸是 Gly 和 Pro。Gly不利于形成 $\alpha$ 螺旋的原因是它的侧链太小，与它有关的二面角变化太大，无法满足 $\alpha$ 螺旋形成所必需的具有相对固定的二面角这个条件。而Pro不利于形成 $\alpha$ 螺旋与两个因素有关：一是它的本质是亚氨基酸，当它的亚氨基与其他氨基酸的羧基形成肽键以后，失去了氢键供体，于是主链上氢键的数目减少，这使螺旋的稳定性下降。二是它的侧链为刚性的环，这使 $\alpha$ 螺旋形成所需要的 $\phi$ 值难以达到。然而，这两个因素的存在并不意味着Pro绝对不能出现在 $\alpha$ 螺旋中。事实上，在少数 $\alpha$ 螺旋中也会发现Pro的踪影，例如视紫红质7次跨膜的 $\alpha$ 螺旋中就有，但它一般只会出现在 $\alpha$ 螺旋的前4个残基之中，并且它的出现会导致螺旋发生小小的弯曲。具有较大R基团或者 $\beta$ 碳上有分支的氨基酸，如Ile、Val、Thr、Phe和Trp，因为容易产生空间位阻，所以也不利于 $\alpha$ 螺旋的形成。Ser、Asp和Asn在侧链上靠近主链的位置含有氢键供体或受体，容易与主链上的氨基H或羰基O竞争形成氢键，故也不利于形成 $\alpha$ 螺旋。侧链带有电荷的氨基酸（Glu、Asp、Lys和Arg等）如果带同种电荷的连续排列，也不利于 $\alpha$ 螺旋的形成。

除 R 基团的大小、形状和带电状态之外，螺旋具有的偶极矩（dipole moment）也能影响到螺旋的稳定性。由于稳定 $\alpha$ 螺旋的氢键几乎都平行于螺旋轴，使得每一个肽键的固有偶极“连为一体”，螺旋的总偶极矩成为一个净偶极矩，其正极在 N 端，负极在 C 端（图 3-13）。虽然偶极矩的存在不利于螺旋的稳定，但蛋白质可以借助螺旋本身 R 基团带负电荷的 N 端酸性氨基酸和 R 基团带正电荷的 C 端碱性氨基酸，来中和偶极矩的存在使螺旋两端带有的相反电荷，从而消除其对螺旋稳定性带来的不利影响。此外，还可以通过相邻螺旋之间以反平行的方式相互作用，相互中和各自在两端的电荷，来降低偶极矩对螺旋的去稳定作用。此外，有些蛋白质通过 $\alpha$ 螺旋在 N 端带有的正电荷与带负电荷的配体分子（如磷酸基团）结合，或者通过在 C 端带有的负电荷与带正电荷的配体（如金属离子）结合，来消除偶极矩对螺旋的稳定性产生的不利影响。

对于一个稳定的 $\alpha$ 螺旋而言, 主链上的原子埋在螺旋的内部, 彼此之间通过范德华力结合在一起, 里面几乎已没有任何空隙, 这让所有的 R 基团都呈辐射状离开螺旋的核心, 充分展示在螺旋的表面。螺旋的这种性质, 方便了它们与其他部位的氨基酸残基的侧链或者与其他生物分子(如 DNA)之间发生相互作用。

螺旋的上述性质可用螺旋轮（helical wheel）作图表示。1个螺旋轮是螺旋沿着螺旋轴的二维投射图，具体作图步骤是：首先想象有1条与螺旋轴平行、垂直于纸平面的直线 $(0^{\circ})$ 。其顶端(正对读者)表示螺旋的第1个氨基酸的侧链，用画圈的数字1表示它的位置；然后，按顺时针方向转 $100^{\circ}$ 画第2条直线，使其一端在螺旋轴，另一端用画圈的数字2表示第2个氨基酸；再从第2条直线向顺时针旋转 $100^{\circ}$ 画第3条直线，依次类推，直到将螺旋上的所有氨基酸都画上。注意，离我们越近的数字圆圈轮要画得越大。按照这种作图方法，第5圈以后，图的样式将会重复，即第19号位的氨基酸残基将位于1号位残基的上面。

使用螺旋轮作图,可显示出各氨基酸残基侧链在螺旋边缘的分布情况,有助于判断1个α螺旋是亲水的,还是疏水的,或是两亲的(图3-14)。如果螺旋上的亲水氨基酸较多,则螺旋可视为亲水的;如果全部是疏水氨基酸,螺旋则是疏水的。疏水α螺旋要么分布在球状蛋白质的内部,要么出现在膜内在蛋白的跨膜区,这是因为蛋白质的内部和膜内部的环境都是疏水的。例如,在很多真核细胞的质膜上,有一类叫G蛋白偶联的受体(参见第十八章“激素”),这类受体属于跨膜蛋白,共跨膜7次。每1个跨膜的肽段形成的都是疏水α螺旋;如果亲水残基和疏水残基含量差不多,并且亲水的分布在螺旋一侧,形成亲水的一面,疏水的集中在另一侧,组成疏水的一面,那么这样的螺旋称为两亲螺旋(amphipathic helix)。两亲螺旋的疏水面通常与蛋白质内部的疏水区结合,而亲水面与水相互作用。此外,两亲螺旋还发现在许多载脂蛋白分子中,这些载脂蛋白通过两亲螺旋的疏水面与脂质结合,亲水面则暴露在水溶液之中。

（5）反平行 $\beta$ 折叠的每一个残基上升 0.347 nm，二面角 $(\phi, \psi)$ 约为 $(-135^{\circ}, +140^{\circ})$ ，平行 $\beta$ 折叠的每一个残基则上升 0.325 nm，二面角 $(\phi, \psi)$ 约为 $(-120^{\circ}, +105^{\circ})$ 。

因为平行 $\beta$ 折叠没有反平行 $\beta$ 折叠稳定, 所以前者一般会有更多的 $\beta$ 股, 很少低于 5 个, 并且, $\beta$ 股总是被包埋在蛋白质的内部, 而后者含有的 $\beta$ 股可以低到 2 个, 其一面经常暴露在水相之中。

不管是哪一类 $\beta$ 折叠，在两边的 $\beta$ 股上总会有一些羰基O和氨基H没有参与形成 $\beta$ 折叠内部的氢键，因此要通过其他方式来满足它们形成氢键的需要。这些方式包括：(1)若 $\beta$ 股正好暴露在水相之中，就与水分子形成氢键。(2)若 $\beta$ 股在蛋白质的内部，可以与其他二级结构（如 $\alpha$ 螺旋）上的亲水残基的侧链形成氢键。(3)若 $\beta$ 股在蛋白质的表面，就与其他有相同问题的蛋白质分子的表面 $\beta$ 股形成 $\beta$ 折叠。(4)构成 $\beta$ 折叠的所有 $\beta$ 股在空间上发生一定的扭曲，以便让第一股和最后一股靠近，即首尾相连而形成氢键，以致这些 $\beta$ 股聚集在一起，形成一种伸展的右手扭曲结构（extended right-handed twist）。这样的结构实际上是一种结构模体(见后)，存在于多种蛋白质分子的核心。

如果 $\beta$ 股交替出现疏水和亲水残基,那么就可以形成两亲 $\beta$ 折叠。这样的结构常见于孔蛋白（porin）。孔蛋白是一种膜蛋白,由两亲 $\beta$ 折叠构成 $\beta$ 桶（ $\beta$ -barrel）结构。在 $\beta$ 桶结构中,非极性残基的侧链伸向膜脂的疏水区,极性残基则埋在内部形成亲水通道,允许极性分子通过膜(图 3-18)。

有时,2个蛋白质分子在特定的条件下,可以各提供1个β股形成β折叠,从而导致两者瞬间结合,形成临时的复合物(例如真核细胞内的Raf蛋白和Rap蛋白)。这种情况经常出现在细胞的信号转导过程中。

## Box3-2 生化大师的传奇——感冒期间的感悟

在 20 世纪 30 年代, William Astbury 发现湿的羊毛或发丝一旦发生显著的伸展, 其 X 射线衍射显示出的结构就会有很大的变化。他所得到的数据似乎表明, 没有伸展的羊毛和毛发纤维形成的是一种螺旋状的结构, 其螺距约为 0.51 nm。

一开始, Astbury 提出, 羊毛和毛发纤维形成了一种弯曲的链结构, 后来又提出没有弯曲的纤维形成的是螺旋, 并称之为 $\alpha$ 型, 而伸展可导致螺旋解旋, 形成 $\beta$ 型结构。

虽然 Astbury 提出的两种模型结构在很多细节上是错误的,但是其核心内容却是正确的,与后来两种标准的二级结构——α 螺旋和 β 折叠刚好相对应。事实上,提出 α 螺旋和 β 折叠的三位科学家 Linus Pauling(图 3-19)、Robert Corey 和 Herman Branson 保留了 Astbury 的命名规则。Hans Neurath 首先显示了 Astbury 模型的细节是错误的,原因是这个模型导致原子在空间上发生冲突。不过,Neurath 相关论文和 Astbury 得到的数据也启发了 H. S. Taylor 和 Maurice Huggins 等人,让他们在解释角蛋白结构的时候,尝试用新的模型去取代 Astbury 的模型。

在现代 $\alpha$ 螺旋模型建立的过程中, 有 2 个关键的进展十分重要: 一是对氨基酸和肽的晶体结构的确定, 以及 Pauling 对肽键平面性质的正确预测, 导致与化学键几何形状相关的问题得以正确处理; 二是敢于放弃每一圈螺旋的残基数目必须是整数的观念。2 个进展的融合发生在 1948 年的早春, Pauling 因感冒住院。无聊至极, Pauling 在思考构成蛋白质的肽链结构: 他用一支铅笔和几张白纸, 在白纸上画出大致正确的多肽链结构, 并尝试将纸折叠成螺旋状, 同时小心地让肽键平面结构不被破坏。凭借对化学键特别是氢键结构的深入了解, 在经过数次尝试以后, 他提出了靠氢键来稳定的螺旋结构。在出院以后, Pauling 和他的同事 Corey、Branson 一起对模型进一步优化, 最后在 1951 年 2 月 28 日, 将相关论文投给美国科学院院刊 (P.N.A.S.) 并很快得以发表, 这一天刚好是 Pauling 的 50 岁生日。事实证明, Pauling 提出的 $\alpha$ 螺旋模型正确得难以置信, 包括键长这个细节, 其精度在 40 多年都没有受到挑战过。但遗憾的是, 他当时并没有考虑螺旋的手性。事实上, 发表在 P.N.A.S. 上那篇题为 “The Structure of Proteins: Two Hydrogen-Bonded Helical Configurations of the Polypeptide Chain” 的论文中, 画的 $\alpha$ 螺旋结构的示意图是左手螺旋。现在, 我们都知道, 自然界的 $\alpha$ 螺旋几乎都是右手螺旋。

α 螺旋的发现是生物化学发展史上里程碑的事件,特别是 Pauling 在提出 α 螺旋的过程中所使用的体外建模的方法,后来被 Watson 和 Crick 在研究 DNA 双螺旋结构过程中所采用。如今在生化和分子生物学研究之中,经常采用的计算机辅助分子建模,这实际上就是 Pauling 最初使用的体外模型建立的延伸。

Pauling 因对化学键性质的研究及其在阐明复杂物质(蛋白质)结构方面的应用而荣获 1954 年的诺贝尔化学奖,后来他还得过 1962 年的诺贝尔和平奖。在诺贝尔奖历史上,Pauling 至今仍然是唯一一位独享两次诺贝尔奖的人。

## (三) $\beta$ 转角

为了在同一条肽链上形成 $\beta$ 折叠, 或将一条多肽链上的 $\alpha$ 螺旋与 $\beta$ 折叠组合在一起, 多肽链的主链经常需要改变方向, 形成弯曲或回折, 而 $\beta$ 转角就可以达到这样的目的。

β 转角也称 β 弯曲（beta-bend）、β 回折（beta-reverse turn）或紧密转角（tight turn），其主要特征如下所述。

(1) 主链发生了 $180^{\circ}$ 方向的改变。

（2）由肽链上4个连续的残基组成，Gly和Pro经常出现在中间两个残基的位置。这是因为Gly的R基团最小，很容易调整其在β转角中的位置，降低与其他残基(尤其是R基团大的残基)之间可能形成的空间位阻，而Pro则具有相对刚性的环状结构和固定的 $\phi$ ，在某种程度上能迫使转角的形成。

(3) 在构成 $\beta$ 转角的 4 个残基之中, 只有 1 号位残基的羰基 O 与 4 号位残基的氨基 H 形成氢键, 其余位置的氢键供体和受体之间并没有相互形成氢键, 但它们可以在蛋白质的表面, 与水分子共筑氢键。正因为如此, $\beta$ 转角通常出现在球状蛋白质的表面。已发现蛋白质的抗体识别、磷酸化、糖基化和羟基化位点经常出现在 $\beta$ 转角和紧靠 $\beta$ 转角。此外, 在水溶液中的小肽分子中也发现了类似 $\beta$ 转角的结构。

（4）有利于反平行 $\beta$ 折叠的形成。这是因为 $\beta$ 转角改变了肽链的走向，促进前后相距不远的两个肽段各自作为 $\beta$ 股，形成 $\beta$ 折叠。

β转角有三种类型,前两种类型(Ⅰ型和Ⅱ型)的差别仅仅在于第2个残基和第3个残基形成的肽平面的朝向(相差180°)(图3-20),第三种类型(Ⅲ型)则有重复的二面角,( $\phi,\psi$ )等于(-60°,-30°),与3 $_{10}$ 螺旋接近。Ⅰ型转角更为常见,它的3号位最适合Pro,而Ⅱ型的2号位最适合Pro,3号位适合Gly和其他小的亲水氨基酸。无论是哪一种类型,4号位最适合Gly,而1号位经常是Asn、Asp、Ser和Cys。

## (五) 环与无规卷曲

在蛋白质分子中,除了上述几种有规律的二级结构,还有一些极不规则的二级结构,它们柔性强,涉及的二面角变化大,但也不是任意变动的,这些结构一开始统称为无规卷曲。

环曾长期被归为一种无规卷曲结构,但随着对其结构和功能认识的深入,人们越来越倾向于将其视为一种独立的二级结构。环作为蛋白质三维结构中最重要的动态结构元件,一般位于球状蛋白质的表面,在很多地方充当将有规律的二级结构联系在一起的纽带(图3-22),其侧链和主链部分通常含有各种结合位点和功能位点,并以动态的方式作为控制与蛋白质相互作用的配体进入的“门户”。已发现的与环有关的生物功能包括:分子识别、与其他蛋白质相互作用、与配体结合、参与或控制酶的催化等。从进化的角度来看,相同的蛋白质家族的不同成员在功能上的差异通常是由蛋白质表面的结构变化引起的,而这些变化经常发生在环上。因此,环结构的突变是蛋白质进化产生新活性和新功能的常见手段。

## 三、蛋白质的三级结构

Quiz10 肽键从反式变成顺式是构象还是构型的变化？

三级结构是指构成蛋白质的多肽链在二级结构的基础上,进一步盘绕、卷曲和折叠,形成的包括所有原子在内的完整的三维(three-dimensional,3D)结构。三级结构通常由模体(motif)和结构域(domain)组成。一种蛋白质的全部3D结构又可以称为它的构象(conformation)。但注意不要将构象与构型(configuration)混为一谈。构型是指在立体异构中,一组特定的原子或基团在空间上的几何排布。两种不同构型(如D/L型或者顺式/反式双键)的转变总是伴随着共价键的断裂和重新形成。然而,一个蛋白质可以存在几种不同的构象,但不同构象之间的转变仅仅是单键的自由旋转造成的,并无共价键的断裂和再形成。构成蛋白质的多肽链上存在多个单键,因此一种蛋白质在理论上可能具有许多不同的构象。然而在生理条件下,一种蛋白质只会采取一种或几种在能量上有利的构象。

## （一）稳定三级结构的化学键

稳定三级结构的化学键主要是非共价键，其包括氢键、疏水键、离子键、范德华力(图3-23)。有的金属蛋白还借助于金属配位键来稳定3D结构。此外，属于共价键的二硫键也参与稳定许多蛋白质的3D结构。

## (1) 氢键

凡是与电负性很强的原子(如 O 和 N)相连的 H 原子,由于带部分正电荷,可以作为氢键供体,与另一个电负性较强的带部分负电荷的原子(如 O 和 N),即氢键受体,通过静电吸引相连,以这种方式形成的化学键叫氢键。氢键除了用来稳定蛋白质二级结构,在维持三级结构方面也起着重要作用。不过,稳定二级结构的氢键供体和受体来自主链,而

稳定三级结构的氢键供体和受体一般则来自亲水氨基酸的侧链基团,例如羟基氨基酸的羟基和酸性氨基酸的羧基。

氢键的键能为 $12 \sim 30 \, kJ \cdot mol^{-1}$ ，比共价键弱得多。但由于蛋白质分子中存在许多氢键，键多力量大，故其在稳定蛋白质三级结构中仍有很大贡献。

## (2) 离子键

离子键是带相反电荷的离子或基团之间的静电引力(electrostatic interaction)，其键能为100~500 kJ·mol $^{-1}$ ，在蛋白质中常称为盐键(salt bond)或盐桥(salt bridge)。在生理pH下，肽链上的碱性和酸性氨基酸残基的侧链分别带正、负电荷，此外游离的N端氨基和C端羧基也分别带正、负电荷，所有这些带电荷的基团都可以形成盐键。

## (3) 疏水键

疏水基团或疏水分子在水溶液里为了避开水相而互相聚集在一起形成的作用力称为疏水键（hydrophobic bond）或疏水作用力，其键能小于 $40\ kJ\cdot mol^{-1}$ 。蛋白质分子中的疏水基团主要由疏水残基的侧链提供，它们聚集在一起的时候会在蛋白质分子内部形成一个疏水核心。这种疏水作用既是驱动蛋白质折叠的主要动力，又是稳定已折叠好的蛋白质的三级结构最重要的化学键。如果构成一个蛋白质的所有氨基酸残基都是亲水的，那么用来驱动三级结构形成的力将十分有限。而如果一个蛋白质既含有亲水氨基酸又含有疏水氨基酸，则有利于它在水溶液中快速地折叠，并到达最终的构象状态。

但需要特别注意的是,疏水键并不是发生在疏水基团之间的一种主动吸引力,而是一种受热力学第二定律驱动的作用力。将疏水基团集中在蛋白质内部的疏水核心在能量上是有利的,因为它降低了疏水基团与水分子之间不利的作用,反而使疏水基团之间的范德华力大大增加。如图3-24所示,两个疏水基团A和B若单独存在的话,其表面会附着更多有序的水分子,所以熵比较小;然而,这两个疏水基团若聚合在一起(A-B),由于球面积是半径的平方,而体积是半径的立方,那么将有一部分水分子从疏水基团的表面释放出去,进入无序状态,这会导致系统的熵增加。另外,在两个疏水基团因为疏水作用而靠近时,这也为它们之间建立范德华力创造了条件。正因为如此,疏水键和范德华力往往相伴相随,一起对蛋白质的三级结构、核酸的双螺旋结构以及生物膜的脂双层结构等的形成和稳定起决定性作用。

## (4) 范德华力

范德华力（Vander Waals force）是在2个相邻的不带电荷的非成键原子（non-bonded atom）之间的作用力，这种作用力可能是吸引力也可能是排斥力。范德华引力一般有三种形式：第一种为诱导力，源于相邻的不带电荷的非成键原子，因为电荷密度的波动，引发的诱导偶极（induced dipoles）之间的相互吸引。第二种是色散力，源自分子或基团瞬时偶极间的作用力，即由于电子的运动，某一瞬间电子的位置对原子核是不对称的，也就是说正、负电荷重心发生瞬时的不重合，从而产生瞬时偶极。最后一种就是取向力（orientation force），发生在极性分子或基团之间。由于极性分子或基团的电性分布不均匀，一端带正电，一端带负电，形成偶极。因此，当两者相互接近时，偶极的同极相斥、异极相吸。在极性分子或基团之间，三种形式的力都存在；而在极性与非极性分子或基团之间，则存在诱导力和色散力；在非极性分子或基团之间，只存在色散力。


较小的总面积/总体积


二硫键也称为二硫桥,它是在2个Cys残基的S原子之间形成的共价键。对于细菌和真核生物来说,含有二硫键的蛋白质一般是分泌蛋白或者细胞膜蛋白,如抗体、胰岛素、胰岛素受体、动物消化


较大的总面积/总体积

## (5) 二硫键

道内的多种水解酶和多种细菌分泌到胞外的外毒素，而胞内蛋白很少有二硫键。其中的原因一是胞外的环境多变，有时甚至比较恶劣（如胃酸的 $\mathrm{pH} < 2$ ），二是蛋白质也比较小，故疏水作用力相对要弱，这两种因素让这些蛋白质更需要借助共价的二硫键来加固它们的三级结构。何况胞外环境的氧化性较强；相反，胞内的环境一方面还原性强，不利于二硫键的形成，另一方面，胞内的环境相对稳定和温和，也不需要用二硫键来稳定三级结构。然而，对于古菌而言，其胞内许多蛋白质也有二硫键，这显然有助于它们抵抗所生存的极端环境。

## (6) 配位键

配位键是一种特殊形式的共价键,它对一些金属蛋白(metalloprotein)的三级结构具有一定的稳定作用。以羧肽酶A(carboxypeptidase A)为例,该酶蛋白大致折叠成球形,这与1个 $Zn^{2+}$ 与其His69、Glu72、His196的侧链以及1个水分子配位结合形成四面体结构有一定关系。

## （二）研究三级结构的方法

当今,确定蛋白质三级结构的方法主要有四种,前三种是用实验的方法来测定,建立这三项技术的科学家都得过诺贝尔化学奖,而第四种是根据蛋白质的一级结构利用基于人工智能(AI)技术的程序来进行预测,建立这项技术的三位科学家也获得了诺贝尔奖(见后)。

## 1. X 射线晶体衍射 (X-ray crystallography)

这一种方法首先需要制备待测蛋白质的晶体,然后才可以对其进行 X 射线衍射分析。但是,想得到一种蛋白质的晶体并非易事,特别是膜蛋白。此外,X 射线衍射分析得到的并不是原子的直接图谱,而是电子密度图谱。因此,还需要利用专业的傅里叶逆变换(inverse Fourier transform)去分析电子密度,再还原成三维结构(图 3-25)。由此得到的显然是蛋白质分子在晶体状态下的三维结构。这种结构与蛋白质分子在生物体内的天然结构相比可能不尽相同,原因是晶体中的蛋白质分子相互间紧密而有规律地排列在一起,运动性较差,而体内的蛋白质分子大多数处于溶液状态,周围是水分子和其他生物分子,运动性较强。

## 2. 核磁共振波谱法（nuclear magnetic resonance spectroscopy, NMR）

此方法是根据原子核在磁场下的振动情况来分析蛋白质结构,由瑞士化学家 Kurt Wüthrich 于上世纪 80 年代初建立,它的基本原理是:在强磁场中,原子核发生自旋能级分裂,在吸收外来电磁辐射后,会发生核自旋能级的跃迁,产生核磁共振现象。核自旋能级的共振频率与电子类型有关,且受到所处化学结构微环境的影响。由此可提供分子结构包括蛋白质三维结构的信息。

NMR 既可以研究膜蛋白, 又可以直接对溶液中的蛋白质结构进行研究, 因此得到的三维结构也更接近蛋白质在生理条件下的真实构象; 而且, 通过改变溶液的性质, 可以模拟出生物体内的各种生理条件, 以观察周围环境的变化对蛋白质构象的影响; 此外, 它还能研究蛋白质与蛋白质以及与其他分子之间的相互作用。然而, 随着蛋白质所含氨基酸数目的增加, 谱峰数量急剧增大、谱峰增宽、重叠严重、信号减弱、灵敏度下降, 还受到自旋扩散和分子局域运动的影响, 因此此方法一开始限于研究小于 120 个残基的蛋白质, 这就大大地限制了它的使用。而 X 射线晶体衍射的方法对蛋白质的大小没有限制。不过, 随着三维、四维核磁的使用以及蛋白质同位素标记技术的应用, NMR 能够测定的蛋白质大小的上限不断被打破。同样根据 PDB 2024 年 12 月 12 日的数据, 由 NMR 测出三维结构的蛋白质有 14322 种。其中有些蛋白质也使用 X 射线晶体衍射测定过。比较两种方法得到的结果, 可以看出大体上是相同的, 但局部的表面区域由于各自所处的环境不一样而呈现出明显的差异。另外, 许多蛋白质在晶体状态下仍然具有原来的生物活性, 如与配体结合和催化反应等。由此可见, 两种方法得到的结果都是可靠的!

## 3. 冷冻电镜(cryo-electron microscopy, cryo-EM)

这种方法始于上世纪70年代,近几年得以飞速发展,特别是分辨率已经可以和前两种方法相媲美,可以说它已成为当今结构生物学研究普遍使用的一项技术。其基本原理或步骤可简单概括为:先“样品速冻”,即将待测蛋白溶液在-180℃下迅速冷冻;再“冷冻成像”,即获取其二维投影图像;最后进行“三维重构”,即通过分析、计算,得到蛋白质三维密度图,进而确定出三维结构(图3-26)。

现在，冷冻电镜可以快速、简易、高效、高分辨率地解析各种蛋白质及其复合物的三维结构，在很大程度上取代并且超越了传统的X射线晶体衍射法和NMR。再次根据PDB2024年12月12日的数据，由冷冻电镜测出三维结构的蛋白质已有23660种，其中就包括西湖大学校长施一公教授所获得的葡萄糖转运蛋白、钾离子通道和人源脂类外向转运蛋白 $\mathrm{ABCA}_1$ 等蛋白质。

## 4. 基于 AI 技术的程序进行结构预测

近些年来,包括 AlphaFold2 和 RoseTTAFold 等程序在内的强大机器学习 (machine learning) 算法经过训练,让研究者仅根据氨基酸序列就可以快速、准确地预测出一种天然蛋白质精细的三维结构。机器学习是一种人工智能,它允许计算机在没有明确编程的情况下从数据中深度学习,从而可用于对人类难以理解的复杂科学问

题进行建模,为蛋白质三维结构的研究带来了革命性的变革。如果没有此类程序的帮助,可能需要数年的实验室工作才能确定一种蛋白质的结构。在2021年夏天,AlphaFold2帮助获得了来自几乎所有生物体的2亿种蛋白质的预测结构(参见https://alphafold.com)。正因为如此,该成就被Science评为2021年的年度突破,而与此相关的John M. Jumper、Demis Hassabis和开发RoseTTAFold的Darid Baker一起分享了2024年的诺贝尔化学奖。

与 AlphaFold2 相比, RoseTTAFold 是一种 “三轨” 神经网络, 这意味着它同时考虑蛋白质序列的模式、蛋白质的氨基酸如何相互作用以及蛋白质可能的三维结构。在这种架构中, 一级、二级和三级结构信息来回流动,使网络能够集体推理蛋白质的化学部分与其折叠结构之间的关系。如果要使用AlphaFold2进行预测,可以访问有关网址,按照页面上的提示进行操作;如果要使用RoseTTAFold进行预测,可以访问https://robetta.bakerlab.org,同样按照页面上的提示进行操作。

然而, AlphaFold2 等 AI 程序预测出的是蛋白质的静态结构(图 3-27), 并不能反映蛋白质在行使功能的过程中所经历的结构变化。要知道, 即使是具有明确单一结构的蛋白质通常也不会在空间上静止不动。例如, 酶在催化时多少会发生构象的变化。因此, AlphaFold2 预测的蛋白质结构可能与 X 射线晶体衍射结果一样, 只显示一个固定不变的结构, 并不会展示任何随着不同配体结合(如血红蛋白与 $\mathrm{O}_2$ 的结合)而发生变化的结构。另外, AlphaFold2 等程序所获得的蛋白质结构是预测出来的模型结构, 并不是通过实验测出来的结构。

## （三）三级结构的表示方法

在获得一种蛋白质的三维结构以后,可以用以下6种常见的模型(图3-28)展示出来。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-08-24/bdf1f0ec-2681-4a52-947a-a73255dca489/bf9298699a9542216fb22444f3e6e4ba5aa1fe61029428063256ab6a3cab4d42.jpg)



图 3-28 各种表示蛋白质三维结构的模型


（1）线框（wire-frame）模型——用线框表示蛋白质主链及其侧链，以显示蛋白质分子在三维空间上的轮廓。

（2）球棍（ball and stick）模型——用球代表成键原子，棍代表原子之间的共价键，以此显示蛋白质分子的三维结构。

（3）棍式（stick）模型——用细棍代表原子间的共价键，但原子本身并没有显示出来。

（4）空间填充(space-filling)模型——用重叠的球来表示成键原子,球的直径由范德华半径决定。此模型能更真实地显示出蛋白质分子的外形,但很难从模型中看见它的键角,因此很多重要的结构信息没有展示出来。

(5) 骨架(backbone)模型——用粗的线条显示蛋白质主链在空间上的走向。

（6）丝带（ribbon）模型——用不同形状的丝带显示构成蛋白质分子各种二级结构在三维空间内的排布。此模型虽不能显示构成蛋白质分子的各个原子在空间上的具体排布，但能显示与蛋白质三维结构相关的重要的二级结构信息。

## （四）三级结构的结构部件

构成一种蛋白质三级结构的部件一般包括模体和结构域。此外，真核生物很多蛋白质还带有内在无序区域（intrinsically disordered region, IDR）或天然无结构区域（natively unstructured region, NUR）。

## 1. 模体

在结构生物学上, 模体这个概念有两种不同的用法: 第一种用在一级结构上, 专指具有特殊功能的特定氨基酸序列或核酸分子上的碱基序列, 被称为序列模体 (sequence motif)。例如, 能够与整联蛋白 (integrin) 结合的细胞外基质蛋白一般含有 RGD 序列模体。再如, 定位在内质网腔的蛋白质在 C 端都含有 KDEL 序列模体 (参见第四十二章 “翻译后加工”)。模体的第二种用法表示的是结构模体 (structural motif), 相当于超二级结构 (super-secondary structure)。如果一种结构模体对应于一种特定的生物功能, 那么这种结构模体可称为功能模体 (functional motif)。

结构模体介于蛋白质二级和三级结构之间,由相邻的二级结构单元彼此相互作用,组合在一起,形成一种在空间结构上易于辨认的有规律的二级结构组合体,并充当三级结构的部件。在多数情况下,主要是疏水残基的侧链参与这些相互作用,而亲水侧链多在分子的外表面。常见的结构模体包括以下几种形式。

（1）卷曲螺旋(coiled coil)。这是一种常见的 $\alpha$ 螺旋聚合体，一般是由2~3股甚至多股 $\alpha$ 螺旋组装而成的一种超螺旋结构(图3-29)。螺旋之间的方向有的是平行，有的是反平行。每一股螺旋通常含有BXXBCXC七肽重复序列(heptad repeat)，这里的B表示疏水氨基酸(经常是Leu)，C表示带电荷(charged)的氨基酸，X表示其他类型的氨基酸。这种有规律的七肽重复序列使螺旋之间能够通过螺旋表面的疏水补丁聚合在一起，形成二聚体或多聚体左手超螺旋，亲水的R基团则暴露在表面。卷曲螺旋不仅作为三级结构的模体参与蛋白质的折叠，而且还参与蛋白质和蛋白质之间的相互作用，因为蛋白质之间可以通过它形成二聚体或多聚体复合物，例如，在真核细胞内，经常发生各种小泡膜与目标细胞器膜的融合，这种融合不是随意的，它依赖于来自小泡膜上的v-SNARE蛋白的一段螺旋，与目标细胞器膜上的t-SNARE蛋白的三段螺旋之间的相互作用，如果能形成稳定的四螺旋束，说明双方的膜是匹配的，就可以融合，否则就融合不了。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-08-24/bdf1f0ec-2681-4a52-947a-a73255dca489/ebe5244ec9fd68fe0e34169019d8f13bb4dea75471fb0688ad63a1a52675360f.jpg)

（2）螺旋-环-螺旋（helix-loop-helix, HLH）。它由两段 $\alpha$ 螺旋和夹在其中的一个环组合而成。其中，有一种特殊的形式叫 EF 手相（EF-hand）。它是一种典型的功能模体，由 E 螺旋、F 螺旋和螺旋之间的一个环组成（图 3-30），存在于多种与 $Ca^{2+}$ 结合的 $Ca^{2+}$ 传感器蛋白上（参见第十八章“激素”）， $Ca^{2+}$ 在环上与蛋白质结合。

## 2. 结构域

纤维状蛋白质呈纤维状,其肽链向同一个方向伸展,但球状蛋白质会卷曲成致密的球状结构。大小低于20 kDa的蛋白质通常呈一个简单的球形,平均直径为2~3 nm,而较大的蛋白质一般会折叠成两个或多个相对独立的球状区域。这些相对独立的球状结构和/或功能模块称为结构域。每一个结构域通常是独自折叠形成的,内部有一个起稳定作用的疏水核心,并含有一个或几个模体结构。

结构域有大有小,但通常不会超过由250个残基组成的单结构域蛋白,其中大多数在200个残基以下,由51~150个残基构成的结构域约占49%。迄今发现的最大的结构域含有907个残基。大的结构域疏水核心较大,故稳定性更好;小的结构域疏水核心较小,因而稳定性较差,经常要借助于金属离子的结合或二硫键来加固。

不同的蛋白质含有的结构域数目不尽相同,以2~3个较为普遍。另外,某些结构域在同一个蛋白质分子上有多个拷贝,即一个蛋白质分子含有多个相同或相似的结构域。有时,两个相邻的结构域之间除了一些起连接作用的外部环和小的肽段,可以发生几乎完美的重叠(图3-34)。一般认为,这样的蛋白质是通过基因重复(gene duplication)的方式进化而来的,即一个结构域是另外一个结构域的复制品。对于某些蛋白质,复制的结构域与母体结构域在序列上具有一致性,而对于其他一些蛋白质,经过多年的进化,序列跟母体相比已变得面目全非。复制的结构域是否与原来的结构域具有一致性,则取决于复制事件已经历了多长时间,以及指导它趋异的功能对原序列的影响。显然,基因复制得越古老,积累的突变就越多,从而使序列之间的亲缘关系变得模糊。以大肠杆菌的硫酯酶(thioesterase)为例,它有两个结构域在大小和形状上几乎完全相同,但氨基酸序列差之甚远,这显然是几百万年的随机突变造成的。

在结构和功能上, 结构域是相对独立的。许多蛋白质的结构域在特殊的条件下被人为地分开以后, 每一个结构域仍然保留各自原有的功能。例如, 大肠杆菌 DNA 聚合酶 I 含有三个结构域, 分别有 DNA 聚合酶、3'外切核酸酶和 5'外切核酸酶的活性。使用胰蛋白酶可以将其中的一个小结构域和另外两个结构域分开。利用这种方法游离出来的小结构域保留了 5'外切核酸酶活性, 另外两个结构域保留了 DNA 聚合酶和 3'外切核酸酶活性。在许多参与激活基因转录的激活蛋白分子上, 结构域所具有的相对独立性更是表现得淋漓尽致: 这些激活蛋白一般有两个结构域, 一个负责与 DNA 特异性结合, 另一个负责激活基因的表达。当将 DNA 结合结构域与一种本来并不能结合 DNA 的蛋白质 A 融合, 再将激活基因表达的结构域与另外一种并不能激活基因表达的蛋白质 B 融合以后, 令人惊奇的是, 如果 A 和 B 能够发生特异性相互作用, 那么在结合以后, 竟然能够作为一个整体, 去激活报告基因 (如绿色荧光蛋白) 的表达。有人正是根据这一点, 发明了一种研究蛋白质与蛋白质相互作用的酵母双杂交技术 (参见第四十四章 “分子生物学技术”)。当然, 并不是所有的蛋白质的结构域在被人为分开后, 可以保证功能一定不受到影响。如果一种蛋白质的功能由它的两个结构域共同承担, 那对于这样的蛋白质, 其结构域的分离必然会影响到它的功能。还有一种情形, 就是一个结构域的功能是调节另外一个结构域的活性。例如, 一些酶的活性中心在一个结构域上, 而调节酶活性的别构中心在另外一个结构域上, 显然若将这两个结构域分开, 这些酶的活性将不再受原来的别构中心调节 (参见第十三章 “酶活性的调节”)。

根据占优势的二级结构元件的类型,结构域通常分为4类(参见蛋白质结构域数据库http://www.cathdb.info):(1) $\alpha$ 结构域——完全由 $\alpha$ 螺旋组成。(2) $\beta$ 结构域——只含有 $\beta$ 折叠、 $\beta$ 转角和不规则环结构。(3) $\alpha/\beta$ 结构域——由 $\beta$ 股和起连接作用的 $\alpha$ 螺旋组成,其组成单元是 $\beta\alpha\beta$ 模体。(4) $\alpha+\beta$ 结构域——由独立的 $\alpha$ 螺旋区和 $\beta$ 折叠区组成。构成这4类结构域的二级结构元件可能有不同的组织方式,而每一种组织就是一种结构模体。然而,一些蛋白质结构域可以在没有稳定的三维结构即在无特定三维结构的情况下存在和发挥作用,这类结构域就是前面提及的内在无序结构域(IDR)(详见后面的“3. IDR”部分)。

α 结构域经常含有四螺旋束 (four-helix bundle) 模体, 并行使多种功能, 包括氧气运输、核酸结合和电子传递等。这种模体由 4 个反平行的 α 螺旋聚合而成, 每一个 α 螺旋与下一个相交, 夹角约为 -20°, 于是整个模体向左手弯曲。例如, 蚯蚓肌红蛋白 (myohemerythrin) (图 3-35 上) 和人生长激素就有这种模体。另外一种常见的组成 α 结构域的模体是珠蛋白折叠 (globin fold), 它一般由 8 个 α 螺旋组成, 相互间的夹角为 +90° 和 +50° 。这种模体使结构域内部形成一个疏水口袋, 以容纳大的疏水性的血红素辅基。肌红蛋白只有一个结构域, 功能是贮存氧气, 构成模体的 8 个 α 螺旋环绕其血红素辅基 (图 3-35 下)。类似的模体还发现在另一类含有血红素辅基但参与电子传递的细胞色素分子中。

由 $\beta$ 结构域组成的蛋白质包括免疫球蛋白、几种酶(如超氧化物歧化酶)和细胞表面的一些糖蛋白。因为在相邻的 $\beta$ 折叠股之间没有起连接作用的螺旋,所以全 $\beta$ 结构域实际上只有反平行的 $\beta$ 折叠,在 $\beta$ 股之间起连接作用的是 $\beta$ 转角和较大的环。

在 $\beta$ 结构域内的反平行折叠倾向于将它们的亲水一面面向蛋白质的表面,与水环境接触,而将疏水的一面面向疏水的核心,相互间还可以组装在一起,形成 $\beta$ 桶结构。例如,白蛋白原使用希腊钥匙模体构建 $\beta$ 桶结构域。

## 3. IDR


图 3-36 丙糖磷酸异构酶的 TIM-桶结构域


IDR 在生理条件下处于天然无折叠或无结构状态,缺乏明确的 3D 结构,难以用圆二色光谱(CD)、NMR 和 X 射线晶体衍射进行鉴定和分析,通常在特定条件下便折叠成稳定的有规律的 3D 结构以执行其功能,如与特定配体结合或发生化学修饰,但有的就在无结构状态下执行功能。例如,组蛋白 H1 富含正电荷的 C 端 IDR 在与 DNA 或带负电荷的蛋白质结构域结合以后,就被诱导形成 $\alpha$ 螺旋,从而导致染色质纤维的稳定折叠和寡聚化的形成。此外,有些蛋白质几乎完全是非结构化的,这些蛋白质被称为天然无折叠蛋白(参见下一章有关天然无折叠蛋白的内容)。

已发现,大多数真核蛋白质由结构化区域和 IDR 组成。属于 IDR 的氨基酸序列之所以不折叠,主要是因为缺乏庞大的疏水氨基酸,也就无法形成用来稳定绝大多数结构域所需要的疏水核心。

在功能上,现在已经确定 IDR 积极参与由蛋白质行使的多项功能。这些功能主要分为三类:(1)蛋白质修饰。IDR 在结构上的灵活性,有助于催化翻译后修饰的酶对它的识别和结合。例如,许多 IDR 富含磷酸化的位点,可作为大量激酶和其他修饰酶的底物,其修饰会影响与不同配体结合的亲和力,也可能直接影响到被修饰的蛋白质的活性。(2)分子识别。IDR 构象的柔性和适应性使其能够形成各种结合界面或支架,以结合和识别多种不同的配体。例如,p53 在细胞中可以与多种不同的蛋白质发生相互作用,这主要就是通过它的 IDR 进行的。(3)分子组装。已发现在真核生物体内,有很多蛋白质在特定的条件下,瞬间通过 IDR 凝聚在一起,形成一种由蛋白质凝聚物构成的液滴(droplet),从而发生液-液相分离(liquid-liquid phase separation,LLPS),以此参与胞内的多项功能,如酶活性的调节、信号转导和基因表达调控(参见后面相关章节的内容)。

## 四、蛋白质的四级结构

许多蛋白质(如血红蛋白)不止一条肽链,如果肽链之间不是以二硫键相连,则认为这些蛋白质具有四级结构,其中的每一条肽链都拥有自己的三级结构。

由一条以上肽链组成的蛋白质称为寡聚体（oligomer）蛋白，其中的每一条肽链称为单体（monomer）或亚基（subunit）。含有2、3、4、5或6个亚基的蛋白质分别称为二聚体（dimer）、三聚体（trimer）、四聚体（tetramer）、五聚体（pentamer）或六聚体（hexamer）蛋白，含有更多亚基的蛋白质以此类推。最常见的寡聚体蛋白质是二聚体。由同一种肽链组装而成的寡聚体称为同源寡聚体，否则称为异源寡聚体。

构成异源寡聚体的各个亚基尽管一般由不同的基因编码,且在某些情况下序列很少或没有同源性,但通常在三维结构上很像。这说明许多异源寡聚体起源于一个编码同源寡聚体的原始基因的重复。

## 1. 四级结构的内容

四级结构内容包括亚基的种类、数目、空间排布以及亚基之间的相互作用。

由相同亚基组装的蛋白质通常具有对称的四级结构。如果相互作用的亚基都不一样,也就无对称可言。相同的亚基为了相互作用,其中每一个亚基必须具有结合区域A和它的互补区域 $A'$ ,从而形成一种对称的复合物。受表面的A和 $A'$ 位置的决定,亚基相结合形成封闭的结构,以二聚体或三聚体最常见,或者形成非常少见的末端开放的链状结构(螺旋排列最常见)。组装成的对称复合物的重复单位可能是单体,也可能是由不同肽链组成的复合体。例如,成人血红蛋白由四条肽链组成( $\alpha_{2}\beta_{2}$ ),为对称的二聚体,其重复单位为 $\alpha\beta$ 。在对称复合物中的对称单位称为原体(protomer)。如果亚基上含有第二套互补结合的区域(如B和 $B'$ ),那么它们还能形成更精妙的复合物,因为第二个结合区域使得对称结构能够继续配对。例如,配对的二聚体形成四聚体,配对的三聚体形成六聚体。

## 2. 稳定四级结构的化学键

亚基的表面是不规则的,这使得彼此之间有可能结合,并形成四级结构,而亚基之间是否真正结合不仅与形状的互补性有关,还与将亚基联系在一起的化学键的互补性有关,例如“氢键供体对氢键受体”“正电荷基团对负电荷基团”“疏水基团对疏水基团”。这些互补的性质在所有的结合作用中都可以观察到,无论是蛋白质和小分子之间,还是蛋白质和其他大分子之间。互补是必需的,因为互补性保证了两个结合的分子在界面上形成尽可能多的非共价键。因此,驱动四级结构形成以及稳定四级结构的作用力包括氢键、疏水键、范德华力和离子键,这虽然与稳定三级结构的化学键的种类一样,但四级结构强调的是亚基之间的化学键。虽然亚基之间的结合伴随着有序性的提高而导致熵的减少,这似乎在热力学上是不利的,但是亚基结合使本来暴露在表面的疏水残基埋到亚基间的界面却在热力学上又是有利的,因为这让原本分布在亚基表面的有序水分子减少,从而使熵增加。研究表明,亚基之间的界面通常由约60%的疏水残基和40%的亲水残基组成。就一个典型的寡聚体蛋白而言,结合的两个亚基的解离常数 $K_{d}$ 为 $10^{-16}\sim10^{-8}mol\cdotL^{-1}$ ,这说明了亚基之间的亲和力是相当高的。

非常稳定的寡聚体倾向于在亚基之间包埋更大的疏水表面,而聚合和解聚都很容易并以此作为其功能一部分的亚基似乎利用更多的极性作用力,如氢键。

不适当的四级结构会影响到蛋白质的功能,甚至会产生严重的功能障碍。例如,胰岛素是由 A 链和 B 链通过二硫键相连的一种激素。胰岛素只有以这种无四级结构的单体形式存在,才能与靶细胞膜上的受体结合,继而引发生物学效应。然而,在溶液中,胰岛素能够自发地形成二聚体,二聚体之间还能聚合成六聚体。由于胰岛素分子形成六聚体的结合面就是它与受体结合的区域,因此六聚体胰岛素是无活性的。从胰岛分泌出来的胰岛素是单体,能够迅速作用靶细胞,但若将胰岛素静脉注射到糖尿病患者体内,原来形成的六聚体解离得较慢,致使降血糖效应来得慢,而影响到药效。1988 年,Guy Dodson 使用基因工程的方法对胰岛素进行了定点改造,将其缔合表面上的 1 个 Pro 用 Asp 取代。结果发现,界面上带负电荷的 Asp 产生的静电斥力可阻止单体聚合,从而有助于六聚体解离成单体。若将这种胰岛素变体注射到实验动物体内,发现它比一般的胰岛素能更快地诱发降血糖效应。

## 3. 四级结构形成的意义

形成四级结构使得蛋白质具有特殊的优势,概括起来有:(1)通过减少蛋白质表面积和体积的比率,可提高蛋白质的稳定性。(2)提高遗传学上的经济与效率。如果有大小相同的两种蛋白质,一种只有1个亚基组成,另一种由2个相同的亚基组成,显然编码后者比前者所需要的碱基序列要少,而且表达效率更高。(3)有利于某些酶的活性中心的组装。这是因为形成寡聚体可将分散在亚基上的催化位点集中在一起。许多酶是靠亚基的聚合而获得催化或部分催化能力的。有时,单个亚基可能建立不了一个完整的活性中心,只有形成寡聚体才能将所有必需的催化基团集中在一起,组成一个有活性的酶。例如,大肠杆菌的谷氨酰胺合成酶(glutamine synthetase)的活性中心是由两个成对的亚基组装而成的,而解离后的单个亚基完全没有活性。(4)能产生协同效应(co-operativity)(参见下一章有关血红蛋白的内容)。(5)减少翻译出错的机会。因为与同样大小的单体蛋白相比,构成寡聚体蛋白质的肽链更短,翻译出错的机会就更小(参见第四十一章“mRNA翻译”)。(6)改变一种蛋白质功能的特异性。例如,细菌的RNA聚合酶由σ因子和核心酶组成,结合有σ因子的核心酶可识别启动子,并启动基因的转录,而单独的核心酶只催化转录的延伸(参见第三十八章“DNA转录”)(7)有利于酶活性的调控。许多酶由调节亚基和催化亚基组成(如蛋白质激酶A),当调节亚基与特殊的调节物结合以后,会影响到催化亚基的活性。还有些酶具有无四级结构的单体和具有四级结构的寡聚体两种形式,但只有一种形式有活性。(8)有利于包装成更加庞大的结构。例如,病毒的衣壳通常由多个相同的亚基自组装而成。

## 第三节 蛋白质的折叠历程与结构预测

既然蛋白质的三维结构直接决定其功能,那么如果能够深入了解蛋白质的折叠机制,将会大大促进对蛋白质的功能研究,在此基础上还可以对一些未知蛋白质的结构和功能进行合理的预测。如今科学家对蛋白质折叠的一些基本规律已有所了解,但对蛋白质折叠的详细机制的认识还需进一步完善。

## 一、蛋白质折叠的基本规律

迄今为止,已经被确认的蛋白质折叠的基本规律包括以下几点。

1. 一级结构决定三维结构, 即一种蛋白质的一级结构包含了它折叠成最终构象所需要的全部化学信息。这就是美国科学家 Christian B. Anfinsen 在 1954 年提出的蛋白质折叠的热力学学说 (thermodynamic hypothesis), 也被称为 Anfinsen 法则 (Anfinsen's dogma) (参见本章科学故事)。

有人将包含在一级结构之中驱动蛋白质折叠的信息称为“第二套遗传密码”。就某些蛋白质而言，这些折叠信息是自我识别的，因而它们不需要其他蛋白质的帮助就可以正确地折叠；而对于另外一些蛋白质，这些信息可能也存在，但需要其他蛋白质的帮助以防止错误折叠；还有一些蛋白质，如枯草杆菌素（subtilisin），以前体的形式被合成，在后加工的过程中被切除的肽段充当肽链剩余部分折叠的模板。前枯草杆菌素原作为枯草杆菌素的前体，在N端含有两段前肽序列，一段为信号序列，指导其分泌到胞外，另一段作为折叠的模板。在后加工的时候，先切除信号序列产生枯草杆菌素原，再切除第二个肽段，产生有活性的枯草杆菌素。枯草杆菌素原的变性是可逆的，但枯草杆菌素则不然，这是由于枯草杆菌素已丧失了自我折叠的模板。

## 二、蛋白质折叠的历程

在 Anfinsen 法则被提出以后,人们对于蛋白质在折叠过程中最后如何达到热力学最稳定的构象状态有很大的争议。1969 年,美国科学家 Cyrus Levinthal 对此提出了一种观点:假定一种蛋白质由 100 个氨基酸残基组成,而每个残基有 2 个构象,那么这种蛋白质的总构象数目是 $2^{100} \approx 1.27 \times 10^{30}$ 。再假定此蛋白质为了寻找总能量最低的构象状态,每尝试 1 次构象耗时 $10^{-13}$ s,那么将所有可能的构象都尝试完需要的时间 = $10^{-13} \times 1.27 \times 10^{30}$ (s) = $1.27 \times 10^{17}$ (s) ≈ $4 \times 10^{9}$ (年)! 然而事实上,许多小的蛋白质完成折叠的时间在毫秒甚至在微秒这样的数量级。Levinthal 这种与事实不符的观点常被称为 Levinthal 悖论 (Levinthal's paradox)。

Levinthal 悖论说明,蛋白质折叠不可能是通过随机尝试来获得最后自由能最低的构象状态的,而是只尝试有限数目的构象,或者按照特异性途径进行折叠。于是,科学家研究的重心转移到揭示特异性的折叠途径上。

科学家根据体外实验的结果和计算机模拟等手段得到的数据,提出了三种模型来解释蛋白质的折叠过程(图3-42):(1)框架模型(framework model)。该模型认为,局部的二级结构首先形成,它们独立于三级结构的建立。当折叠好的各种二级结构单元扩散并发生碰撞的时候,便发生了聚合,从而成功形成最终的三级结构。(2)疏水塌陷模型(hydrophobic-collapse model)。该模型认为,蛋白质分子上的疏水侧链快速地发生包埋,即发生疏水塌陷,亲水侧链则

暴露在外,形成熔球体(molten globule)。在熔球体内,远距离基团之间的相互作用得以建立,从而先形成三级结构,最后才形成二级结构。(3)成核模型(nucleation model)。该模型认为,在一级结构上相邻的一些序列自发折叠成特定的二级结构。然后,这些二级结构充当折叠核(folding nuclei),其他结构以此为核心,向周围扩展,逐步形成最终的三级结构。

有人将这三种模型结合起来,认为蛋白质折叠经过三步反应:(1)快速地形成局部二级结构,即折叠核。此过程是可逆的。(2)折叠核协同聚合成结构域。(3)结构域经熔球体,最终形成具有完整三维结构的蛋白质。熔球体被认为是疏水塌陷的结果,这种中间体含有某些二级结构,但还没有形成正确的三级结构。

如果用图 3-43 来表示上述折叠过程, 可能更为形象。蛋白质折叠的全景图好像一个漏斗, 漏斗表面的每一个点代表的是多肽链的一个构象, 蛋白质分子可被视为一组在向下滑行的滑雪者, 下坡滑雪指导多肽链进入它的天然状态。有些蛋白质折叠过程比较 “坎坷”, 有些蛋白质则折叠得比较顺利。蛋白质的天然状态是最深的 “谷底”, 其他山谷代表的是部分折叠的构象状态。

一般认为,驱动蛋白质在水溶液中折叠的动力有:(1)肽链主链上的氢键供体和受体之间形成氢键,而将原来有序结合的水分子释放,从而增加水的熵。(2)疏水侧链倾向聚合以尽可能减少与水接触的面积。(3)亲水侧链面向表面与水接触,增加溶解性。(4)带相反电荷的基团靠近,形成盐桥。(5)在疏水作用力的基础上,疏水基团靠近而产生范德华力。这些作用力也是稳定蛋白质三维结构的因素,而不利于蛋白质三维结构稳定的因素则有:(1)肽链形成有规律的二级结构,使熵减少。(2)将一个极性的基团从水相中移走,却没有让它形成新的氢键。(3)将一个带电基团从水相中移走,却没有带相反电荷的基团和它形成盐键,或者将两个带同种电荷的基团强行放在了一起。(4)将一个疏水基团放在水相中。(5)将两个原子放在同一位置,产生空间位阻。

也许,蛋白质折叠就是这两股相反势力相互较劲最后妥协的结果,仿佛是一个竞赛激烈又相互谦让的游戏。例如,牺牲1~2个氢键却换来了2~3个疏水键,或者将1个疏水基团与水接触却让一种二级结构多了一些氢键。

## Box3-3 大蛋白“能屈能伸”的故事

听过有关泰坦尼克号（Titanic）邮轮故事的人应该都知道，这艘邮轮之所以起这个名字，是因为它是当时世界最大的客运轮船。不过，学过生化的人也应该知道，肌肉组织中有一种蛋白质叫肌巨蛋白（titin），之所以获得这个名称，是因为它被发现时是已知最大的蛋白质，现在已“屈居”第二。一般的蛋白质含有几百个氨基酸残基，最多也就是上千个，而这种巨无霸蛋白居然含有3万多个残基！如果用分子式表示，则是 $C_{169719}H_{270464}N_{45688}O_{52237}S_{911}$ 。

组成蛋白质的氨基酸残基的数目之所以一般控制在千以内, 是因为蛋白质翻译的错误率在 $10^{-3} \sim 10^{-5}$ 之间。控制蛋白质的大小可以减少翻译出错的机会, 即可以在错误还没有发生的时候, 让翻译结束。既然如此, 那为什么肌肉细胞还要冒着翻译出错的危险制造这么大的蛋白质呢? 这实际上与肌肉所行使的特殊功能有关。

1954 年, 美国的 Reiji Natori 首先提出, 肌纤维中应该有一种弹性结构, 这样可以让肌肉在伸展和随后的释放中容易回到静息的状态。1977 年, 日本的 Koscak Maruyama 等人从肌肉细胞中成功分离出一种弹性蛋白, 并将其命名为连接蛋白 (connectin), 经 SDS-聚丙烯酰胺凝胶电泳鉴定, 发现该蛋白质的分子量异常大。2 年后, 中国台湾的 Kuan Wang 等人进一步鉴定, 发现 Maruyama 所说的连接蛋白在电泳的时候, 事实上有 2 条带, 他们把分子量更大的条带代表的蛋白质称为肌巨蛋白。1995 年, 美国的 Siegfried Labeit 等人克隆到心肌细胞中肌巨蛋白的全长 cDNA, 差不多有 100 kb。2001 年, 德国的 Marie-Louise Bang 等人测定了全长肌巨蛋白基因的序列, 发现它共有 363 个外显子, 编码 38138 个氨基酸, 分子量高达 $4.2 \times 10^{6}$ 。在不同的肌细胞中, 已发现了许多肌巨蛋白的变体, 它们是选择性剪接的产物。这些变体长度一般在 27000~36000 个残基, 不过在心肌细胞中发现了一个最小变体只有 5604 个残基。

研究表明,1个肌巨蛋白分子可折叠成将近244个串联排列的结构域,其中112个结构域类似于构成抗体的结构域,还有132个类似于纤维粘连蛋白(fibronectin)的结构域,这些紧密折叠的结构域多位于与肌球蛋白丝作用的部位。

在肌肉组织中, 肌节(sarcomere)是一个最小的收缩单位(图 3-44), 里面的肌巨蛋白在一端即 N 端附着在 Z 线(Z-disk)上, 组织着细的肌动蛋白丝, 另一端即 C 端则附着在 M 线(M-line)上, 组织着粗的肌球蛋白丝, 于是一个肌巨蛋白分子跨越了半个肌节的长度。在 Z 线和 M 线之间, 肌巨蛋白含有许多弹性元件可以伸展和收缩，在肌肉弯曲的时候，可将整个收缩装置保持在合适的形状。因此，肌巨蛋白在肌节中的主要功能是作为一根“分子弹簧”，既参与肌节间力的传递，同时限制肌节运动的范围，在细丝之间防止肌节过分伸展，并使其在伸展以后能像弹簧一样弹回去，因此它对于维持肌节的结构完整，减少异常收缩产生的细微损伤非常重要。

## 三、与蛋白质错误折叠相关的疾病

据估计,正常的细胞约有三分之一的蛋白质可能会错误折叠,但细胞内有专门的质量控制(quality control)系统,能及时发现并加以处理。例如,分子伴侣能够与错误折叠的中间物结合并重启折叠过程。另外,在真核细胞内有一种叫泛素(ubiquitin)的蛋白质,能够将这些错误折叠的蛋白质打上“死亡标签”,并把它们引入到胞内一种没有膜包被的圆筒状细胞器——蛋白酶体(proteasome)内,被“无情”地水解掉,以防止它们在胞内的堆积(参见第四十一章“mRNA翻译”)。因此在一般情况下,细胞内出现少量折叠异常的蛋白质并不会影响到细胞的正常功能。然而,如果一个细胞内大量出现错误折叠的蛋白质,以至于超出了质量控制系统的处理能力时,就可能导致机体的病变。错误折叠的蛋白质对机体造成最大的麻烦就是会聚集在一起,最终形成不溶性的淀粉样纤维(amyloid fibrils)损害细胞,严重的可导致细胞死亡。

近年来,越来越多的疾病被发现与蛋白质异常折叠有关,例如囊性纤维变性(cystic fibrosis, CF)和以海绵状脑病(spongiform encephalopathy, SE)为代表的神经退行性疾病。其中,CF是由于基因突变导致编码的蛋白质不能正确折叠,而神经退行性疾病主要是后天因素导致神经元内出现了一些细小的原纤维(protofibril)。原纤维由4~30个错误折叠的蛋白质形成,可进一步聚合成不溶性的纤维,而不论是原纤维,还是纤维,都会危害细胞。

## (一) 囊性纤维变性

CF 与一种编码囊性纤维变性跨膜传导调节蛋白(cystic fibrosis transmembrane conductance regulator, CFTR)的基因缺陷有关,其中最常见的一种突变是缺失了 508 号位的 Phe。该基因的缺陷导致患者体内缺乏有功能的 CFTR,因此这种疾病是一种隐性遗传病,即编码 CFTR 的 2 个等位基因必须都有缺陷才能致病。

正常的 CFTR 是一种 ABC 转运蛋白(ATP-binding cassette transporter)(图 3-46), 共有 1480 个氨基酸残基, 存在于多种上皮细胞的质膜上, 作为一种受 ATP 调控的 $\mathrm{Cl}^{-}$ 通道, 负责将 $\mathrm{Cl}^{-}$ 从胞内运输出去。它共有 5 个结构域, 其中 2 个为跨膜结构域 (membrane-spanning domain 或 trans-membrane domain, MSD 或 TMD), 每一个 MSD 有 6 个跨膜的 $\alpha$ 螺旋, 这些螺旋都与细胞质基质中的 2 个核苷酸结合结构域 (nucleotide binding domain, NBD) 相连。第一个 NBD 通过 1 个调节结构域 (regulatory domain, R) 与第二个跨膜结构域相连。这个 R 结构域是 CFTR 特有的。研究发现, R 结构域只有受蛋白质激酶 A 催化发生磷酸化以及 NBD 结合了 ATP 以后, CFTR 才有活性。有缺陷的 CFTR 不能正常地折叠, 其折叠中间物不能与分子伴侣解离, 从而导致它不能整合到质膜上, 结果在胞内很容易被降解掉。于是, 缺乏 CFTR 的上皮细胞开始积累 $\mathrm{Cl}^{-}$ 。由于渗透压的缘故, 细胞会不断地吸收周围黏液中的水分, 导致黏液变稠, 特别是在患者的呼吸道内会产生稠厚的黏痰, 而阻碍呼吸, 引起阵阵剧烈咳嗽, 让呼吸道反复受感染。患者平均期望寿命仅为 37 岁。

## （二）海绵状脑病

SE 是一种致命性神经退行性疾病, 因受感染的动物在脑部病变的部位出现海绵状空洞而得名。SE 可以感染多种动物, 例如人的克雅病 (Creutzfeldt-Jakob disease, CJD)、GSS 病 (Gerstmann-Straussler-Scheinker disease)、库鲁病 (Kuru disease)、致死性家族性失眠症 (fatal familial insomnia, FFI)、幼儿海绵状脑病(alpers disease)、山羊和绵羊的羊瘙痒病(scrapie)、鹿和麋的慢性消耗病(chronic wasting disease)以及疯牛病(mad cow disease)等。SE的主要症状包括渐进性痴呆(progressive dementia)和运动机能失调。

SE 的致病因子是一种折叠异常的朊蛋白（prion protein, PrP），因最早被发现与羊瘙痒症有关而简写为 $\mathrm{PrP}^{\mathrm{Sc}}(\mathrm{prion~protein~scrapie})$ 。正常动物也有这种蛋白质，一般简写成 $\mathrm{PrP}^{\mathrm{C}}(\mathrm{prion~protein~cellular})$ 。尽管 $PrP^{C}$ 与 $PrP^{Sc}$ 在一级结构上完全一样，但构象不同。它们的主要差别是（图 3-47）： $PrP^{C}$ 富含 $\alpha$ 螺旋，可溶于水，对蛋白酶敏感，呈单体状态； $PrP^{Sc}$ 则富含 $\beta$ 折叠，其核心部分能抵抗蛋白酶的水解，分子间很容易聚合成淀粉样纤维杆状结构。

PrP $^{C}$ 主要分布在脑细胞,少量发现在淋巴细胞和其他细胞中。PrP $^{C}$ 可能参与大脑细胞间的通讯,并与图 3-47 $\mathrm{PrP}^{\mathrm{c}}$ (左)与 $\mathrm{PrP}^{\mathrm{Sc}}$ (右)在构象上的主要差别

动物的长期记忆有一定的关系。PrP $^{C}$ 在进化上十分保守，由 209 个氨基酸残基组成，含有 1 个链内二硫键，通过糖基磷脂酰肌醇（glycosylphosphatidylinositol, GPI）锚定在质膜的外侧。人类的 PrP $^{C}$ 由位于 20 号染色体短臂上的 PRNP 基因编码。

动物可以通过三种方式得病:受外来的朊病毒感染(如经伤口)、家族性遗传和 $PrP^{C}$ 偶然的折叠错误。无论是何种方式,都是先出现少量“坏蛋白”—— $PrP^{Sc}$ ,而 $PrP^{Sc}$ 一旦出现,自身可以作为坏的模板,与“好蛋白”—— $PrP^{C}$ 结合,并诱导后者向“坏的” $PrP^{Sc}$ 转变。真可谓是“近墨者黑”!当许多 $PrP^{Sc}$ 出现在一个脑细胞质膜上的时候,就在膜上聚集并诱发质膜出现凹陷,形成内体(endosome)。在内体与溶酶体融合后, $PrP^{sc}$ 因为结构特殊,无法被溶酶体中的蛋白酶分解,反而在溶酶体中大量累积,最终涨破溶酶体,使其中的水解酶流出,让神经元大量死亡而产生海绵状空洞,由此导致神经退化和病变。烹调和煮沸都不能破坏 $PrP^{Sc}$ ,因此,感染 $PrP^{Sc}$ 的动物是绝对不能加工食用的,必须将其彻底销毁。

通过同源重组技术可以获得 PRNP 基因被敲除的小鼠, 这种小鼠似乎能正常地发育和生殖, 但却失去了感染 PrP $^{Sc}$ 的能力。通过进一步追踪研究发现, 缺失 PRNP 基因的小鼠还是表现出了一些异常, 如外周神经脱髓鞘, 对缺氧性脑损伤敏感性增强, 睡眠和昼夜节律受到影响, 年老的时候可得小脑共济失调等。

$PrP^{C}$ 与 $PrP^{Se}$ 被认为具有相同的能量状态。幸运的是， $PrP^{C}$ 自发重折叠成 $PrP^{Se}$ 的可能性很低，这是因为两者的转变需要克服非常大的活化能。因此，在正常人的一生中， $PrP^{C}$ 几乎不可能自发转变成 $PrP^{Se}$ 。

家族性朊病毒疾病由 PRNP 基因突变造成。突变降低了 $PrP^{C}$ 重折叠成 $PrP^{Sc}$ 的活化能，使自发形成 $PrP^{Sc}$ 的机会大增。据估计，正常细胞因折叠错误产生 $PrP^{Sc}$ 大概需要 3000~4000 年，而突变引起的活化能降低则使时间缩短到 30~40 年，正好落在一个人正常的生命周期内。

除了在哺乳动物体内发现了朊病毒,科学家在植物和某些种类的酵母中也发现了类似朊病毒的蛋白质。例如,已有7种朊蛋白在酿酒酵母中发现。还有科学家在肉毒芽孢梭菌(Clostridium botulinum)中也发现了朊蛋白。这些朊蛋白一般对宿主细胞无害,反而可能是有益的,这表现在它们能让细胞更好地适应变化的环境。

## 四、蛋白质结构预测

随着 DNA 序列测定技术和基因组学的发展,越来越多的物种的全基因组序列被测定出来。然而,面对浩瀚的基因组序列数据,对科学家来说最大的挑战是它们决定的蛋白质的功能是什么?既然结构决定功能,那首先就需要确定它们的结构,特别是三维结构。确定一个蛋白质的一级结构并不困难,通过其基因的碱基序列就能推断出来,但要在此基础上准确地预测出其三维结构以前并不容易!好在基于AI技术的AlphaFold2等程序的出现,让根据一级结构精确地预测蛋白质三维结构也变得容易起来。

## (一) 二级结构的预测

蛋白质二级结构的预测一开始就要容易一些。这是因为二级结构是一种局部结构，而且不同的氨基酸对不同二级结构的形成具有明显的倾向性。

如表 3-3 所示, 在 20 种常见的蛋白质氨基酸残基中, 有的适合形成 $\alpha$ 螺旋, 有的正好相反, 甚至是 $\alpha$ 螺旋的 “终结者”; 有的适合形成 $\beta$ 折叠或 $\beta$ 转角。例如, 含有 Gly-Pro 或 Pro-Gly 的四肽序列一般意味着转角的出现。

1974 年, P. Y. Chou 和 G. D. Fasman 综合各种氨基酸残基形成不同二级结构的趋势, 提出了预测球状蛋白质二级结构的一套规则: (1) 由≥6 个氨基酸残基组成的肽段, 如果其中的 $P_{\alpha} \geqslant 1.03$ , 且 $P_{\alpha} > P_{\beta}$ , 此外还没有 Pro, 那么, 这个肽段应该形成 $\alpha$ 螺旋。(2) 由≥5 个氨基酸残基组成的肽段, 如果 $P_{\beta} \geqslant 1.05$ , 且 $P_{\beta} > P_{\alpha}$ , 那么这个肽段应该形成 $\beta$ 折叠。(3) 如果一个四肽序列的 $P_{\alpha} < 0.9$ , 且 $P_{t} > P_{\beta}$ , 那么它很可能形成 $\beta$ 转角。

## 第四节 蛋白质与蛋白质的相互作用

几乎每一项生命活动都涉及蛋白质与蛋白质的相互作用(protein-protein interaction)。发生相互作用的蛋白质之间通过非共价键发生物理接触并结合在一起,共同行使功能,因此通过确定与某种蛋白质发生相互作用的其他蛋白质的特性,便可推断出该蛋白质的功能。例如,一个功能未知的蛋白质被发现与一系列参与细胞生长有关的蛋白质有相互作用,那么可以推测该蛋白质很可能也参与细胞的生长过程。而异常的蛋白质之间的相互作用可导致疾病的发生。正因为如此,现在蛋白质之间相互作用也成了一些治疗疾病的药物作用的靶标。那么,蛋白质之间相互作用的方式有哪些呢?细胞有哪些重要的过程与蛋白质之间的相互作用有关系?又如何研究蛋白质之间的相互作用?

## 一、蛋白质之间相互作用的方式

根据作用持续时间的长短,蛋白质之间的相互作用可分为永久性的相互作用和暂时的相互作用。如果是前一种方式,那就意味着发生相互作用的蛋白质之间的结合是不可逆的,一旦结合,便形成稳定的复合物,几乎永不分离。例如,存在于一些代谢途径中的多酶复合物和构成呼吸链的复合体。以丙酮酸脱氢酶复合物为例,它是由三种不同的酶蛋白——丙酮酸脱氢酶、二氢硫辛酸转乙酰酶和二氢硫辛酸脱氢酶相互作用形成的多酶复合物(参见第二十三章“糖酵解”)。如果是后一种方式,那就意味着发生相互作用的蛋白质之间的结合是可逆的,可以结合,也可以解离。这种类型的相互作用更常见。例如,蛋白质激素引发的信号转导一开始涉及蛋白质激素(如胰岛素)与其靶细胞膜上的受体蛋白之间的相互作用;再如,真核细胞周期调控中涉及特定的周期蛋白与依赖周期蛋白的蛋白质激酶(cyclin-dependent protein kinase, CDK)之间的相互作用;还有,真核生物在DNA转录的起始阶段,要在启动子上通过蛋白质之间的相互作用,组装出包括RNA聚合酶和多种基础转录因子在内的起始复合物(参见第三十八章“DNA转录”)。

一般说来,发生永久性相互作用的蛋白质之间发生相互作用的界面的面积大,可以形成的非共价键多而强;相反,发生暂时性相互作用的蛋白质之间发生相互作用的界面的面积小,形成的非共价键自然就少而弱。

## 二、蛋白质之间相互作用的生物学效应

蛋白质之间相互作用参与的细胞功能很多,包括细胞间的相互作用、细胞周期的调控、信号转导、代谢途径酶的组织、DNA复制和基因表达等重要过程。由PPI引发的生物学效应概括起来主要包括以下四个方面。

（1）调节蛋白质的活性,特别是酶蛋白。调节目标蛋白活性的有激活蛋白和抑制蛋白。激活蛋白就是与目标蛋白结合以后,激活目标蛋白的活性,例如周期蛋白就是CDK的激活蛋白;抑制蛋白就是与目标蛋白结合以后,抑制目标蛋白的活性,例如人体肝细胞中的葡萄糖激酶的活性受一种抑制蛋白的抑制。

（2）通过在两个蛋白质活性中心之间形成特殊的底物通道方便转运底物，提高代谢效率(参见第十九章“代谢总论”有关底物通道的内容)。

（3）创建新的结合位点，有利于将其他的蛋白质有序地招募过来。这一种生物学效应普遍存在于DNA复制、转录和翻译等过程中，因为这些过程最后都涉及一个庞大的蛋白质复合物的形成。这里以DNA复制的起始为例：一开始有一种蛋白质直接识别并结合DNA的复制起始区，而一旦它结合，构象就会变化，导致产生一个新的结合位点，可以识别并结合下一种蛋白质，于是第二种蛋白质结合上来了。同理，在前两种蛋白质结合以后，构象同样变化，同样产生了一个新的结合位点，可以识别并结合第三种蛋白质。以此类推，通过这样的方式，先后让多种与DNA复制起始有关的蛋白质有序地结合在DNA复制起始区，最终形成一个可以启动DNA复制的起始复合物（参见第三十五章“DNA复制”）。

（4）通过与不同结合“伙伴”的相互作用来改变一种蛋白质对其结合的小分子配体的特异性。例如，Ras蛋白是一种G蛋白，可与GTP酶激活蛋白结合，也可以与鸟苷酸交换因子结合。若是与GTP酶激活蛋白结合，就催化GTP的水解；若是与鸟苷酸交换因子结合，就将原来结合的GDP替换成GTP（参见第十八章“激素”）。

## 第五节 蛋白质组及蛋白质组学

蛋白质组（proteome）是指某一物种所有基因表达的全部蛋白质及其存在方式，即一个基因组、一个细胞或一种组织所表达的全部蛋白质。

在上世纪80年代初，在基因组计划提出之前，就有人提出过类似的蛋白质组计划，当时称为人类蛋白质索引（Human Protein Index），旨在分析细胞内所有的蛋白质。但由于种种原因，该计划被搁浅。1994年，Marc Wilkins提出了蛋白质组的概念。在后基因组时代，虽然已经掌握了多种生物体的基因组序列信息，并且运用测序技术发现了许多新基因，但对很多基因的功能一无所知。即使是一些已被深入研究的模式生物，如大肠杆菌和酵母，仍然有不少基因的功能不明。为了研究基因组中每一个基因的功能，有必要发展一些大规模、高通量、能集中反映基因功能的实验技术。作为功能基因组学的一个分支，蛋白组学应运而生。蛋白组学是对蛋白质性质和功能的大规模研究，包括对蛋白质的表达水平、翻译后加工以及与其他分子的相互作用的研究，从而可以得到细胞进程在蛋白质水平上的宏观映象。

蛋白质组学也可以分为结构蛋白质组学和功能蛋白质组学。前者需要将一蛋白质组内的各种蛋白质进行分离和鉴定，其主要研究内容包括蛋白质一级和三维结构的解析、种类分析和数量确定；后者则以蛋白质的功能和相互作用为主要目标。

高通量分离蛋白质的一种重要方法是双向电泳（two-dimensional electrophoresis）（图3-50）。这项技术起源于上世纪70年代，应用了50多年并已建立了多种不同细胞及组织类型的资料库(参见https://www.expasy.org)，其原理参见第五章相关内容。


3-50 双向电泳及其结果显示


蛋白质经二维电泳分离后,可以将单个的蛋白样点从凝胶中切割出来,用蛋白酶消化成多个多肽片段,再用质谱仪进行分析、鉴定。质谱的基本原理是:待测样品在特定的条件下可转变为高速运动的离子。这些离子根据质量/电荷比的不同在静电场和磁场的作用下得到分离,使用特定的检测器可记录各种离子的相对强度并形成质谱图。目前主要有基质辅助激光解析电离飞行质谱(matrix-assisted laser desorption ionization-time of flight mass spectrometry,MALDI-TOF MS)和电喷雾电离串联质谱(electrospray ionization-tandem mass spectrometry,ESI-MS)等。前者可获得多肽片段质量的信息,后者可获得多肽片段更加详细的信息。虽然这两种质谱的操作截然不同,但原理没有本质上的差别。利用串联质谱结合肽质量指纹图谱(peptide mass fingerprint,PMF),可以初步推测蛋白质的种类和序列。PMF的基本原理是将蛋白质直接从双向电泳凝胶上切下或转移到聚偏氟乙烯(Polyvinylidene fluoride,PVDF)膜上后切下,经过原位酶解得到酶解肽段,然后用质谱得到这些肽段的PMF。由于每种蛋白质的氨基酸序列都不同,在蛋白质被酶解后,产生的肽片段序列也不同,其肽混合物质量数具有一定的特征性,故用实测的肽段质量去查找蛋白质和核酸序列库,结合适当的计算机算法,便可鉴定出蛋白质。

对于蛋白质之间的相互作用以及有关蛋白质功能的研究分别参见上一节和下一章相关的内容。

总之，蛋白质组学是当今生命与生物技术最活跃、最前沿、应用最广泛的领域之一。就像在基因组学研究中，最吸引我们的是人类自己的基因组一样，在蛋白质组学研究中，最吸引我们的同样是人类自己的蛋白质组。为了早日搞清楚人类的蛋白质组，2001年4月，在美国成立了国际人类蛋白质组研究组织（Human Proteome Organization, HUPO），此后在欧洲、亚太地区也都成立了区域性蛋白质组研究组织，试图通过合作的方式，融合各方面的力量，推进对人类蛋白质组的研究。2003年，有两个重要的类似HGP的人类蛋白质组研究计划几乎同时被提出来：一是人类蛋白质图集（Human Protein Atlas, HPA）项目，二是人类蛋白质组计划（Human Proteome Project, HPP）。迄今为止，这两项人类蛋白质组研究计划已基本完成了。

## 科学故事——“一级结构决定三维结构”学说的提出

“蛋白质的三维结构是由其一级结构决定的”学说最初由 Christian B. Anfinsen 于 1954 年提出。该学说也被称为 Anfinsen 法则 (Anfinsen's dogma)。

在 1950 年之前, Anfinsen(图 3-51)一直从事蛋白质结构方面的研究。在进入美国国立卫生研究所(NIH)以后,他仍然从事这方面的研究。在研究中,他一直想解决的问题就是:一个蛋白质分子是如何折叠成其独特的三维构象的?其中需要不需要其他酶的帮助?蛋白质为什么要采取特定的构象?

然而,要想了解蛋白质的折叠过程先要解决两个问题:其一是建立一种测定蛋白质构象的方法,其二是找到一种检测折叠过程的手段。Anfinsen 以牛胰核糖核酸酶(ribonuclease)为研究对象轻而易举地解决了第一个问题。实际上,Anfinsen 选用此酶纯属偶然,部分原因是当时离他工作的研究所不远的地方,有一家肉类加工厂能为他的实验室随时免费提供足够的原材料。由于核糖核酸酶催化 RNA 的水解,其酶活性完全取决于其特有的三维构象,于是酶活性成为测量这种蛋白质采取何种构象的一种方法。至于观测折叠过程,既可以在体内从一个新合成的尚没有折叠的蛋白质开始,也可以在体外将一个已折叠好的蛋白质去折叠(unfold),然后再观察它的重折叠(refold)过程。Anfinsen 选择了后一种途径。事实上,这种酶特别适合用后一种途径进行研究。首先,因为二硫键是决定其分子形状的主要因素;其次,此酶只有一

3-52 Anfinsen 实验


在成功得到一种去折叠的核糖核酸酶以后, Anfinsen 着手开始研究它的重折叠过程了。考虑到被还原的核糖核酸酶要在已被还原的 8 个 Cys 残基上重建 4 个二硫键, 这可有 105 种不同的组合, 但只能有一种是正确的形式。如果决定蛋白质构象的信息一直存在于氨基酸序列之中, 那么, 最后重折叠得到的就应该总是那种正确的形式。否则, 重折叠将是随机的, 最后只能得到少量的正确形式。显然, 第一种情形能完全恢复去折叠过程中丧失的酶活性, 而后一种情况只能恢复很少的酶活性。

Anfinsen 的重折叠实验还是比较顺利的,他通过透析的方法除去了导致酶去折叠的尿素和巯基乙醇,再将没有活性的酶转移到生理缓冲溶液中,在有氧气的情况下于室温放置,以使巯基能重新氧化成二硫键。经过一段时间以后,他们发现绝大多数核糖核酸酶的活性得以恢复,这意味着它原来的构象恢复了。由于上述过程没有细胞内任何其他成分的参与,完全是一种自发的过程,因此有理由相信,此蛋白质正确折叠所需要的所有信息全部存在于它的一级结构之中。很快在 1954 年,Anfinsen 的研究成果被发表在某一期的 Journal of Biological Chemistry 上了。他们通过进一步的实验,还确定了去折叠的核糖核酸酶完全恢复其活性的条件。在此基础上,Anfinsen 提出了蛋白质折叠的热力学学说(thermodynamic hypothesis)。此学说认为,一个蛋白质的天然三维构象对应于它在生理条件下所处的热力学最稳定的状态。热力学稳定性由组成的氨基酸残基之间的相互作用决定,所以蛋白质的三维构象直接由它的一级结构决定。

尽管 Anfinsen 的工作奠定了蛋白质折叠的热力学基础,他也因此得到了 1972 年的诺贝尔化学奖,但是蛋白质折叠是相当复杂的,特别是在细胞内的折叠比在体外折叠要复杂得多!
